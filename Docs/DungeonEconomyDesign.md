# 던전 경영 생존 게임 기획

> 상태: 핵심 규칙과 현재 구현 범위를 빠르게 확인하는 기준 문서. 세부 설계는 `Docs/Design/`의 기능별 문서를 따른다.

## 한 줄 목표

플레이어는 계속 영업하는 던전을 확장·방어·경영해 모험가 파티의 돈을 빼앗고, 운영비와 부채를 버티며 끝없이 강해지는 보스 주기를 넘긴다.

핵심 감정은 **"시간은 멈추지 않고, 이 파티를 놓치면 이번 주가 무너진다"**이다.

## 확정된 게임 흐름

```text
Start → SampleScene → 영업 준비 → 낮/밤 영업 → 웨이브 종료
    → 7일마다 정산·계약·유닛 상점 → 다음 주
```

- 끝없는 판이다. `WaveConfig.finalDay = 0`이며 1~28일은 직접 작성한 웨이브를 반복한다.
- 7·14·21·28일은 청산일이자 보스일이다.
- 청산일 최소 상환을 못 하거나, 보스별 패배 조건을 만족하거나, 메인 유닛이 쓰러지면 게임오버다.
- 런 난수(노드, 후보, 사건, 파티, 판매 목록 등)는 저장 뒤에도 같은 결과가 나와야 한다.
- 수동 저장과 주요 상태 변경 뒤 자동 저장을 지원하며, 런 종료 시 현재 런 저장을 지운다.

## 시간과 운영

- 낮에는 파티가 많이 오고, 밤에는 약한 파티가 적게 오며 아군 회복·피해 감소 보정이 있다.
- 일반 영업에서는 일시정지할 수 있지만, 엘리트나 보스가 던전에 있으면 자동 재개되고 재정비가 잠긴다.
- 건설·유닛 배치·회수는 일시정지 중에만 한다. 같은 방에 적이 있으면 유닛 이동·회수도 못 한다.
- 공사·수리·철거·함정 재사용은 게임 시간을 사용한다.
- 일차 전환과 주요 사건은 게임을 멈추며, 한 번의 전환에는 가장 우선순위 높은 사건 하나만 낸다.

## 경제·부채·계약

- 시설 수입은 이용 완료 시 정산 예정 장부에 기록하고, 영업 종료 정산에 반영한다.
- 유닛 유지비·시설 운영비·필수 비용은 일차마다 청구한다. 금화가 부족하면 부채가 된다.
- 대출 한도는 기본 상품 한도에 던전 등급·자산·시설·수입·상환 이력 보정을 더한다.
- 당일 필수 비용으로 한도를 넘어도 영업은 끝까지 진행한다. 영업 종료 전 해소하지 못하면 신용 경고 또는 파산이 발생한다.
- 신용 경고는 5단계다. 단계가 오를수록 이자와 최소 상환이 늘며, 5단계에서 다시 한도를 넘으면 파산한다.
- 계약은 주간 정산에서 갱신·변경한다. 빚이 있으면 현재 계약을 연장해야 한다.

## 던전·시설·함정

- 새 노드는 소·중·대 크기, 연결 방향, 시설 여부, 특수 효과를 열기 전에 공개한다.
- 확장에는 금화·공사 시간이 들며 공사 중에는 길·배치·시설 기능이 막힌다. 취소는 일부 환불한다.
- 한 방은 수익 시설 또는 경비 유닛 중 하나를 받는다. 함정만 유닛과 함께 둘 수 있다. 금고는 경비가 가능한 예외다.
- 시설은 독립 대기열·동시 이용 인원을 가지며, 대기 만족도는 수입·목적 변경·불만 탈출에 영향을 준다.
- 시설 내구도는 이용·전투·사건으로 줄고, 낮으면 수입·기능이 약해진다. 0이면 멈추며 수리만 가능하다.
- 함정은 방 안 타일을 차지하며, 밟기·범위·투사체·지속형과 각자 재사용 시간을 가진다.

## 모험가 파티

- 파티는 낮/밤, 날짜, 던전 등급, 시설 규모에 따라 등장 수·인원·강함이 달라진다.
- 목적(시설 이용·보물 약탈 등)과 성격에 따라 최단·안전·보상 경로의 가중치를 다르게 사용한다.
- 일반 노드는 한 파티가 점유하고, 뒤 파티는 대기·우회한다. 시설 노드는 자체 대기열을 쓴다.
- 파티는 공동 자금을 쓴다. 시설 결제와 금고 약탈금이 지갑을 거치며, 사망·전멸 시 일부 또는 전부를 떨어뜨린다.
- 죽은 파티원은 관 상태로 동행하며, 교회에서는 공동 자금으로 체력 비례 부활할 수 있다.
- 소문(함정·사망·후퇴)은 살아 나간 파티가 옮기며 이후 파티의 위험 경로 판단에 반영된다.

## 유닛·부활·판매

- 유닛은 주간 정산의 상점에서만 사고, 판매 목록은 청산일에 갱신된다.
- 가격은 정가에 등급·레벨·특성·난수 시세를 반영한다. 유지비와 능력 정보는 구매 전에 보여 준다.
- 대기 명단 유닛은 유지비·체력·피로 변화가 없고, 배치 유닛만 전투와 유지비에 참여한다.
- 사망 유닛은 마력으로 먼저 죽은 순서대로 부활한다. 비용은 기본값·레벨·고용가·특성 보정으로 정한다.

## 등급·보스·메타 진행

- 던전 등급은 전투 성과, 자산, 시설, 확장, 운영 기간, 수입, 상환 실적으로 오른다.
- 등급은 유닛 한도·판매 목록·마력·대형 노드·고급 시설을 열지만, 더 강한 파티와 보스도 부른다.
- 보스는 탈출하지 않으며 핵심 노드 침입, 핵심 유닛 처치, 제한 시간 같은 전용 패배 조건을 가진다.
- 런 종료 화면은 결과 통계와 해금 결과를 보여 준다. 진행도는 유닛·함정·시설·이벤트·시작 보정을 새 런 후보에 추가한다.

## UI 기준

- 기준 해상도는 1920×1080이며, 인게임 지도 영역을 최대로 유지한다.
- 상단 HUD는 시간·일차, 금화·부채, 마력, 등급, 배속·일시정지, 정산 정보, 파티 위험을 표시한다.
- 방·시설·유닛 상세는 선택 때만 열고, 건설·배치·함정 조작은 하단 행동 영역에서 시작한다.
- 정산은 시간 정지 전체 화면이며 `요약 · 수입 · 지출 · 계약/부채 · 유닛 상점`을 제공한다.
- UI Toolkit 구조와 화면별 배선은 `.claude/rules/ui-rules.md`와 `Docs/Design/RoomManagementUiDesign.md`가 기준이다.
