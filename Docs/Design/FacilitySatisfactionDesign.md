# 시설 대기 만족도 설계

## 목표

시설 대기열은 선입선출을 유지하되, 오래 기다린 모험가는 해당 방문에서 더 적게 지출하고 다른 시설을 찾는다.

## 규칙

- 시설 대기열에 들어간 뒤 실제 이용을 시작할 때까지의 게임 시간을 대기 시간으로 기록한다.
- 대기 1초마다 해당 방문의 만족도는 5%p 감소한다.
- 수입은 만족도에 비례해 감소하며, 최대 감액은 50%다. 따라서 어떤 경우에도 시설 이용 총액의 50%보다 적게 받지 않는다.
- 상점 특성 등 기존 모험가 지출 보정은 만족도로 조정된 기본 지출에 계속 적용한다.
- 시설 폐쇄·파괴로 대기열을 떠나는 경우에는 수입과 마모를 추가하지 않는다.
- 대기가 10초에 도달하면 같은 방문 목적에 맞고 이동 경로가 있는 다른 운영 시설을 탐색한다. 이후에도 대기 중이라면 게임 시간 1초 간격으로 다시 확인한다.
- 대체 시설이 있으면 현재 대기열에서 빠져나온다. 포기한 시설은 이번 모험가의 목적지 후보에서 제외해 같은 줄에 다시 서지 않는다.
- 대체 시설이 없으면 계속 기다린다. 대기 이탈만으로 방문 완료나 탈출을 처리하지 않는다.
- Toolkit 방 상세는 이용 수/정원·대기 인원과 최장 대기 시간을 두 줄 고정 영역에 표시하고, 대기에 따른 최대 수입 감액을 함께 안내한다.

## 범위

현재 수입 감액과 대체 시설 탐색, 방 상세 대기 시간 안내를 구현한다. 시설·성격별 임계점, 극단적 탈출, 시설 기능 약화와 개별 만족도 표시는 이후 단계에서 추가한다.

## 2단계 — 시설·성격별 속도와 개별 표시 (2026-10-14)

> 상태: 구현, EditMode `FacilityQueueTests` 7개. 실측(2026-10-27): 상점 줄의 감소 속도 0.05/초(특성 없음)·이용 시작 만족도(대기 2.99초 → 0.849, 6.60초 → 0.669)·FIFO 확인. 특성 배율·대체 시설 탐색·불만 탈출은 표본이 없어 실측 안 함. 사용자 선택: 시설 × 성격 · 모험가 상태 패널. 수치는 밸런싱 전 초기값이다. 극단적 탈출(성격별 참을성)은 이미 있다.

### 감소 속도

대기 1초당 만족도 감소 = 시설 기준값 × 성격 배율. 최대 감액 50%는 그대로다.

| 시설 | 기준값 |
|---|---|
| 주점·큰 주점(`Inn`) | 3%p — 쉬러 온 손님은 느긋하다 |
| 대장간(`Blacksmith`) | 4%p |
| 상점·무기 상점(`Store`)과 그 밖 | 5%p (1단계 값) |

| 성격 | 배율 |
|---|---|
| 겁쟁이 | ×1.5 |
| 성직자 | ×0.8 |
| 쇼핑광 | ×0.6 |
| 그 밖 | ×1 |

### 임계점

- 대체 시설 탐색은 만족도가 바닥(감액 50%)에 닿는 때 시작한다 = 50% ÷ 감소 속도. 예: 상점의 겁쟁이 6.7초, 상점의 일반 10초, 주점의 쇼핑광 27.8초.
- 불만 탈출은 성격별 참을성(겁쟁이 12·기본 18·성직자 22·쇼핑광 28초)을 따르되, 탐색 시작 + 2초보다 이르지 않다. 찾아볼 틈도 없이 떠나지 않게 한다. 보스는 떠나지 않는다.
- 수치는 `FacilityDwellRules`(`QueuePenaltyPerSecond`·`QueueSatisfaction`·`AlternativeSearchSeconds`·`EscapeWaitSeconds`)에만 둔다.

### 표시

모험가 상태 패널(`EnemyStatusToolkitView`)의 수치 칸에 한 줄을 더했다(카드 312 → 336, 수치 칸 96 → 120).

```text
만족도 70%  ·  상점 대기 6초  ·  4초 뒤 딴 곳 찾음
만족도 50%  ·  상점 대기 11초  ·  7초 뒤 떠남
만족도 85%  ·  주점 이용 중
마지막 이용 만족도 85%
시설 대기 없음
```

### 범위 밖

- 시설 기능 약화를 만족도로 거는 것(지금은 내구도로만 약해진다).
- 머리 위 만족도 표시.
