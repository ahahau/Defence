# 첫 청산 보스 서사 보강 설계

2026-10-27. 앞선 유물 조합·연속 사건을 마친 뒤 이어갈 콘텐츠의 구현 전 제안이다.

## 실제 설정

WaveConfig.asset의7일차 보스는 토벌대장이다. 보스 체력 배율3·공격 배율1.5, 시간 제한150초, 호위 전멸 후 방어 약점8·공격 간격×0.7의 최종 단계, 교회 부활 불가다. 현재 전날 정산과 당일 준비에 패배 조건을 예고하고 등장/격노 배너를 표시한다. 이 설정과 판정은 유지한다.

## 콘텐츠와 표시 위치

| 시점 | 수정 문구 (`\n`은 표시 줄바꿈) | 화자·표시 방식 |
|---|---|---|
| 6일차 정산 | 주인님, 토벌대가 길목에 깃발을 세웠습니다.\n호위를 끊으면 대장의 방패에 빈틈이 생깁니다. | 임프 참모 보고. 기존 보스 예고 안에 연결하며 실제 제한 시간/패배 조건은 별도로 유지 |
| 7일차 준비 제목 | 첫 청산일 · 토벌대장 | 기존 위협 제목 |
| 7일차 준비 힌트 | 호위부터 제압: 방어 약화, 공격 가속 | 설명 문구. 방어 약화의 이점과 공격 가속의 대가를 함께 표시 |
| 등장 | 대열을 갖춰라. 이 던전은 오늘 끝낸다. | 토벌대장 대사. 기존 등장 배너 부제 |
| 격노 | 대열이 무너져도, 나는 물러서지 않는다.\n방어 약화 · 공격 가속 | 첫 줄은 토벌대장, 둘째 줄은 전투 상태 안내. 기존 최종 단계 배너 부제 |
| 7일차 영업 성공 | 토벌대의 깃발이 바닥에 내려앉았습니다.\n주인님, 던전의 문은 아직 우리 손에 있습니다. | 임프 참모 보고. 성공한 보스 영업의 정산 후일담 |

정산 기본 화면의 승리 메모는 "토벌대장 격파 · 첫 공세 방어 성공"의 짧은 요약을 쓰고, 상세에서 후일담 전문을 보여 준다. 별도 대화 모달·화면·클릭 단계는 추가하지 않는다. 패배 화면에는 실제 실패 원인을 계속 표시한다.

## 코드·에셋 범위

- WaveConfigSO.BossEntry에 선택적 예고/승리 문구를 추가한다. 값이 없는 보스와 기존 씬은 현재 동작을 유지한다.
- WaveManager가 문구를 제공하고, 영업이 실제 성공 종료했을 때만 승리 후일담이 나오도록 상태를 구분한다. 보스만 처치하고 영업이 남았거나 판이 패배한 경우에는 승리 메모를 만들지 않는다.
- ManagementSettlementManager는 기존 보스 예고에 문구를 연결하고 성공한 보스 날의 후일담을 기록한다. 금화/부채 계산이나 정산·저장 이벤트 순서는 바꾸지 않는다.
- Unity CLI Editor API로 WaveConfig.asset의7일차 위협 제목/힌트, 보스 문구를 연결한다. 다른 일차 편성·배율·제한 시간·보상·저장 형식·UI 배치는 변경하지 않는다.

## 최소 확인

문구 제공·6일차 예고·7일차 성공 메모와 실패/미완료에서 승리 문구가 나오지 않는 관련 검사, 필요한 빌드/재컴파일, 에셋 읽기 확인만 수행한다. 장시간 전투·밸런스 실측은 진행하지 않는다. 작업은 Sequences.md에 기록한다.

## 문안 수정 이력 (2026-10-27)

사용자가 구현 대신 서사 문구 수정을 먼저 선택했다. 임프 참모는 짧은 보고, 토벌대장은 지휘관의 직접 대사로 구분했다. 호위 제압이 유일한 승리 조건인 것처럼 단정하지 않고 약점 노출의 기회로 설명한다. 준비/격노 안내에는 방어 약화와 공격 가속을 함께 적는다. 승리 후일담은 공세를 막았다는 내용이며 부채 상환이나 판 전체 승리를 단정하지 않는다. 이번 단계는 문서만 수정했으며 코드·에셋 적용은 아직 승인받지 않았다.
