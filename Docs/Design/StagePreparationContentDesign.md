# 초반 준비 사건과 첫 보스 소개

2026-11-02. 사용자가 기획의 미구현 내용을 우선하도록 요청했다. 아래는 기존 EarlyDayEventsDesign/FirstBossNarrativeDesign의 방어 전환 방향을 구체화한 안이다.

**2026-11-02 사용자 승인·구현:** 수치 +20G/코어 +2(임시), ESC로 닫으면 미선택 보존 + 준비 단계 "보급품" 버튼으로 다시 열기, 보스 소개는 1스테이지만. 아래 "구현 결과" 절을 따른다.

## 1. 첫 보스 소개

첫 스테이지에서 최초 보스가 편성된 웨이브의 준비 단계에 임프 참모의 짧은 소개를 표시한다. 보스/호위 이름과 인원은 현재 StageWave에서 읽는다. 메인 금고를 노리는 침입자임을 설명하고, 호위를 함께 상대할 방어선·코어 도달 위험·살아 있는 보스의 일시정지 잠금을 안내한다. 스킬 이름/역할을 언급할 때에는 실제 연결 데이터에서 확인한 내용만 사용한다.

기존 범용 알림 팝업을 사용하며 확인 뒤 준비를 계속한다. 팝업 확인만으로 웨이브를 시작하지 않는다. 오류/설정/다른 팝업이 있을 때는 표시를 미룬다. 같은 씬의 같은 준비 진입 중에는 자동 반복하지 않으며, 이어하기/재도전에서는 다시 읽을 수 있다. 소개에 보상이나 새 패배 조건은 없다.

## 2. 초반 방어 준비 선택 사건 1개

첫 스테이지 첫 웨이브를 방어한 뒤 둘째 웨이브 준비에서 한 번 제안한다. 기존 경영 사건의 민심/피로/시설 마모/대출 효과는 가져오지 않는다.

제목: 남은 보급품

임프 참모: “남은 보급품을 금화로 바꾸거나 금고 보수에 쓸 수 있습니다.”

| 선택 | 제안 효과 |
|---|---|
| 금화로 교환 | 현재 스테이지 금화 +20G |
| 금고 보수 | 현재 코어 내구도 +2, 최대 내구도까지 |
| 사용하지 않음 | 효과 없이 사건 완료 |

**+20G/+2는 승인 전 임시 제안이며 기존 기획 확정 수치가 아니다.** 금고가 최대 내구도라면 보수 선택을 비활성화하고 이유를 표시한다. 확인된 효과와 현재 적용 가능한 실제 회복량을 선택 전에 보여 준다. 선택은 한 번만 적용하며 ESC로 닫으면 미선택 상태로 보존한다. 미선택 때문에 웨이브 시작을 강제 차단하지 않으며, 해당 준비를 떠나면 사건은 지나간다.

## 3. 저장·수명

현재 준비 체크포인트에 사건 선택 결과를 선택 필드로 보존한다. 선택 결과와 적용된 금화/코어 내구도를 같은 스냅샷에서 캡처·복원해 이어하기 후 중복 적용을 막는다. 옛 체크포인트의 누락 필드는 미선택으로 읽되 과거 웨이브에 소급 적용하지 않는다. 재도전은 스테이지 자원 초기화와 함께 사건도 새 시도로 시작하며 영구 재화를 지급하지 않는다.

스테이지 변경/씬 이탈/비활성화/파괴 뒤 남은 팝업 콜백이 이전 세션에 작용하지 않도록 대상 세션·준비 웨이브·시도 식별자를 다시 검사한다. 현재 저장 보호 오류가 있으면 사건 효과를 적용하지 않는다. 신규 스테이지 전용 흐름으로 연결하고 구 SampleScene의 일반 사건/대화 실행은 유지한다.

## 4. 구현과 검증 범위

기획서 갱신 → 스테이지 전용 사건/소개 상태와 표시 담당 분리 → 세션/준비 저장/기존 범용 팝업 연결 → Runtime/Editor 빌드·Unity 재컴파일·콘솔 오류 확인 순서로 진행한다. 별도 씬/프리팹 YAML 편집이나 사용자 저장 파일 변경은 하지 않는다. 테스트·플레이·모의 입력·프리뷰·저장 왕복 금지는 유지하며 실제 동작 검증 한계를 기록한다.
