# 방 관리 화면 통합 설계 (노드 패널 → UI Toolkit)

> 상태: 설계 확정(2026-10-14, 사용자 선택: HUD로 통합 · 카드+상세+설치 · 방 상세에 관리 모음 · 화면 사각형 튜토리얼 강조). 1~5단계 구현(2026-10-14), 테스트·실측은 아직(사용자 요청으로 보류).
>
> 구현하며 바뀐 점
> - 패널: 팝업 패널(10000)이 아니라 HUD와 같은 공용 패널(`RuntimePanelSettings`, Sort Order 0)에 문서 순서 150으로 띄운다. uGUI 튜토리얼 덮개(900)보다 위에 뜨면 덮개가 버튼을 못 가려 아무 버튼이나 눌린다. 아래에 두면 덮개가 가리고 구멍만 눌려 `TutorialInputGate`에 덜 기댄다. 대신 HUD 일시정지 메뉴보다 위라서 메뉴를 열 때 방 관리 화면을 치운다.
> - 설치 창 카드: 136×150, 한 쪽 5장(760 폭에 6장이 안 들어감). 쪽 버튼은 글자(이전/다음).
> - 화면을 그리는 쪽은 뷰(`RoomDetailView`·`InstallPanelView`, MonoBehaviour 아님) + 프레젠터(`RoomDetailPresenter`·`InstallPanelPresenter`)로 나눴다. 컨트롤러는 조립·이벤트·ESC·튜토리얼 조회만 한다.
> - 설치 판정은 `InstallAvailabilityRules`(Buildings)로 뺐다. 실제 설치가 거절하던 "유닛이 선 방의 건물"도 이제 미리 막는다(전에는 결제 뒤 환불).
> - 하단 '보유 유닛' 서랍은 목록 보기만 한다. 배치는 '유닛 배치' 갈래나 방 상세의 '배치'로 한다.

## 목표

방 하나를 고르고 그 방에 무엇을 두고 어떻게 관리할지를 **한 창구**에서 끝낸다. 지금은 같은 일을 하는 화면이 둘이라, 어느 쪽으로 해도 되지만 기능이 한쪽에만 있는 상태다.

## 지금 상태

| 기능 | Toolkit HUD (`GameplayHudToolkitView`) | uGUI 노드 패널 (`NodePanelView`) |
|---|---|---|
| 방 선택 요약 | 선택 말풍선 + 방 상세 패널(유닛 수·시설·이용·내구도·설치물) | 제목만 |
| 건설·함정·시설 목록 | 하단 버튼 → 한 줄 목록, 누르면 바로 위치 선택 | 우하단 '설치' → 갈래 카드 → 항목 카드 → 건물 정보 + 설치 버튼 |
| 유닛 배치 | 보유 목록에서 고르고 '유닛 배치' | 유닛 갈래 → 배치 카드 → 칸 선택 |
| 철거·휴업·수리 | 없음 | 버튼 있음 |
| 유닛 명령·이동·회수 | 없음(회수는 부하 상태 패널에도 있음) | 관리 창(명령 목록·이동할 방 목록) |
| 튜토리얼 강조 대상 | 없음 | 설치 버튼·갈래 카드·첫 카드·포탈 카드·첫 배치 카드 등 8곳(RectTransform) |

- 실제 설치·배치·철거·결제·미리보기 경로는 `NodePanelView`가 갖고 있고, HUD도 `TryBeginBuildingPlacement`·`TryBeginUnitPlacement`로 그 경로를 빌려 쓴다.
- 살아 있는 튜토리얼은 `PlayTutorialView`다. `DialogueRunner`의 옛 안내 튜토리얼은 씬에서 꺼져 있다(`useGuidedStartTutorial: 0`).

## 결정

1. **HUD로 통합한다.** 하단 행동 바와 방 상세가 방 관리의 유일한 창구가 된다. uGUI 노드 패널 화면은 끈다.
2. **`NodePanelView`는 화면 없는 방 관리 로직으로 남긴다.** 설치 요청·미리보기·결제·배치·철거·휴업·수리 경로와 이벤트 구독은 그대로 두고, uGUI 참조와 그리기 코드를 걷어 낸다. 씬 컴포넌트·이름은 유지한다(씬을 고치지 않기 위해). 이름 정리는 씬 정리 때 한다.
3. **설치 목록은 카드 + 상세 + 설치.** 카드를 고르면 상세가 뜨고 '설치'를 눌러야 위치 선택으로 넘어간다.
4. **방 상세에 관리를 모은다.** 시설 줄(내구도·수리/휴업/철거)과 유닛 줄(소속 유닛 → 명령·이동·회수)을 방 상세 안에 둔다.
5. **튜토리얼은 화면 사각형으로 비춘다.** Toolkit 화면이 강조할 곳의 화면 사각형(왼쪽 아래 원점 픽셀)을 내주고 `PlayTutorialView`가 그것을 비춘다(팝업과 같은 방식). 잘못된 클릭은 기존 `TutorialInputGate` 논리 검사가 막는다. 꺼져 있는 옛 안내 튜토리얼 코드는 옮기지 않고 정리한다.

## 화면

모든 영역은 고정 크기다(ui-rules 10번). 새 UXML은 `Assets/GameModules/UI/UxmlAndUss/Battle/RoomManagement/`에 두고, 기존 HUD 문서(`Resources/UI/Toolkit/GameplayHud.uxml`)와 별개 문서로 띄운다(`ToolkitScreenSO`, 공용 패널 위 `PopupPanelSettings` 문서 순서 350). HUD 문서에서는 옛 `node-detail-panel`·`installation-panel`을 뺀다.

### 1. 방 상세 패널 (오른쪽, 400 × 640)

```
┌ 방 이름 · 크기 · 특수 효과 ─────── [닫기] ┐
│ 상태 한 줄 (일반 방 / 침입 입구 / 공사 중)  │
├ 시설 ──────────────────────────────────┤
│ 시설 이름 · 운영 상태                     │
│ 내구도 막대  12/20 · 수입 80%             │
│ 이용 2/3 · 대기 1명 · 최장 대기 4초         │
│ [수리 48G] [휴업] [철거 +25G]             │  ← 상태별로 이름·잠금 이유가 바뀜
├ 유닛 ──────────────────────────────────┤
│ 2 / 3   [배치]                            │
│ ▸ 블루 슬라임 Lv2 · 대기 · HP 18/20       │  ← 최대 4줄, 고르면 아래 줄이 열림
│ ▸ 그림자 암살귀 Lv1 · 돌격 · HP 9/12       │
│   명령 [대기][경비][돌격][휴식]            │
│   이동 [→ 방 선택…]  [회수]               │
├ 설치물 ────────────────────────────────┤
│ 가시 함정 ×2 · 화살 함정 ×1                │
└ 안내 한 줄 (일시정지하면 관리할 수 있습니다) ┘
```

- 선택 말풍선의 '상세 보기'나 방 클릭으로 연다. 방을 바꾸면 내용만 바뀐다.
- 버튼은 숨기지 않고 잠근다. 잠긴 이유는 버튼 글로 줄이고(예: "같은 방에 적"), 전체 문구는 버튼 아래 안내 줄에 쓴다.
- 이동은 '방 선택' 상태로 들어가 지도에서 방을 누르게 한다(지금 노드 패널의 이동 목록과 같은 판정 `UnitManagementSystem.CanMove`).

### 2. 설치 창 (하단 행동 바 위, 760 × 360)

```
┌ 건설 / 함정 / 시설 / 유닛 배치 ──────────── [닫기] ┐
│ [카드][카드][카드][카드][카드]   ◀ ▶ (6장 넘으면 쪽) │  ← 카드 120×150: 그림·이름·값·한 줄 효과
├──────────────────────────────────────────────┤
│ 선택한 항목 상세                               │
│ 건설 40G · 운영비 0G/일 · 위험 2 · 2×1칸         │
│ 효과 한두 줄 / 막힌 이유(빨강)                   │
│                                  [설치]        │
└──────────────────────────────────────────────┘
```

- 하단 행동 바의 '건설·함정·시설·유닛 배치'가 갈래다. 옛 갈래 카드 단계는 없앤다.
- 카드를 고르면 상세가 뜨고 '설치'로 위치 선택(미리보기)에 들어간다. 설치를 시작하면 창은 접히고, 취소하면 같은 갈래로 돌아온다.
- 유닛 배치 갈래는 보유 유닛 카드(이름·레벨·마력·특성)를 보여 주고 '배치'로 칸 선택에 들어간다. 하단 '보유 유닛' 서랍은 목록 보기만 남긴다.
- 항목 목록·해금·설치 가능 판정은 지금처럼 `NodePanelView.EnumerateToolkitInstallOptions`와 `CanInstallBuilding`을 쓴다. 막힌 항목도 카드로 보이고, 상세에 이유를 적는다(지금은 목록에서 빠져 왜 없는지 모른다).

## 튜토리얼 강조 대응

`PlayTutorialView`의 잔걸음을 새 화면에 맞춘다.

| 잔걸음 | 지금 대상(uGUI) | 바뀐 대상(Toolkit 화면 사각형) |
|---|---|---|
| PickNode | 지도 방 | 그대로 |
| OpenInstall | 노드 패널 '설치' 버튼 | (없앰 — 갈래 단계와 합침) |
| PickCategory | 갈래 카드 | 하단 행동 바의 해당 버튼 |
| PickCard | 첫 건물 카드·포탈 카드·첫 배치 카드 | 설치 창의 해당 카드 |
| PressInstall(새로) | 없음(카드 클릭이 곧 설치) | 설치 창 '설치' 버튼 |
| ConfirmRoom | 확장 팝업 | 그대로 |
| PickCell | 지도 칸 | 그대로 |
| OpenRoster·HireUnit·CloseRoster | 유닛 영입 패널(uGUI) | 그대로(영입 패널은 주간 유닛 상점 작업 뒤 옮김) |

- 화면 사각형은 `PopupView.TryGetButtonScreenRect`와 같은 환산을 공용 도우미(`ToolkitScreenRect`)로 빼서 쓴다.
- 덮개(uGUI)는 Toolkit 화면 클릭을 막지 못한다. 그래서 튜토리얼 중 설치 창·방 상세의 버튼은 `TutorialInputGate`(`AllowsInstallCategory`·`AllowsBuildingInstall`·`AllowsHireUnit` 등)로 막는다. 지금도 노드 패널이 같은 검사를 한다.
- 옛 `DialogueRunner` 안내 튜토리얼의 노드 패널 참조(`HighlightCurrentTutorial*`, `*Rect`)는 지운다. 씬에서 꺼져 있다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `NodePanelView` (유지) | 방 관리 로직: 선택 방, 설치 요청·미리보기·결제·설치, 배치·칸 선택, 철거·휴업·수리, 이벤트 구독. uGUI 필드·그리기 제거. 화면에 줄 상태를 묻는 공개 API(아래)를 추가 |
| `RoomManagementController` (새) | 방 상세·설치 창을 조립하고 `NodePanelView`와 잇는다. HUD 하단 버튼이 이것을 부른다 |
| `RoomDetailView` + `RoomDetailViewModel` (새) | 방 상세 그리기만. 시설·유닛 줄의 버튼 콜백을 올려 보낸다 |
| `InstallPanelView` + `InstallCardViewModel` (새) | 설치 창 그리기만. 카드 선택·설치·쪽 넘기기 콜백 |
| `ToolkitScreenRect` (새) | 요소 → 화면 사각형 환산(튜토리얼·팝업 공용) |
| `GameplayHudToolkitView` (수정) | 방 상세·설치 목록 코드를 걷어 내고 하단 버튼을 컨트롤러로 넘긴다(지금 900줄이 넘어 더 키우지 않는다) |
| `PlayTutorialView` (수정) | RectTransform 대신 화면 사각형을 받는 경로 추가, 잔걸음 표대로 대상 교체 |

`NodePanelView`에 더할 조회 API(화면이 상태를 그리는 데 필요):

- `SelectedFacility`, `CanRepair/Close/Demolish(out reason)`, `RepairCost`, `DemolishRefund`
- `EnumerateInstallCards(category)` — 막힌 항목 포함, 각 항목의 설치 가능 여부와 이유
- `EnumerateRoomUnits()`, `CanCommand/CanMove/CanRecall(unit, out reason)`, `BeginMoveSelection(unit)`

## 진행 순서

1. `NodePanelView` 조회 API 추가 + 로직/그리기 분리(uGUI 그리기는 아직 남겨 둠).
2. 방 상세 패널(시설 줄·유닛 줄) Toolkit 구현, HUD의 옛 방 상세 제거.
3. 설치 창(카드·상세·설치·유닛 배치 갈래) 구현, HUD의 옛 한 줄 목록 제거.
4. 튜토리얼 화면 사각형 경로와 잔걸음 교체, 옛 안내 튜토리얼 참조 정리.
5. uGUI 노드 패널 화면 끄기(`panelRoot` 숨김 유지, 그리기 코드 제거). 건물 정보 패널(`BuildingInfoPanelView`)은 설치 창 상세가 대신한다.
6. 한 번에 테스트·실측(사용자 요청: 작업을 다 끝낸 뒤).

## 검증 계획

- EditMode: 설치 카드 목록이 해금·방 크기·시설/함정 겹침 규칙과 일치(막힌 이유 포함), 시설 버튼의 잠금 이유(수리 중·닫힘·청산일 등), 유닛 줄의 명령·이동·회수 잠금 이유가 `UnitManagementSystem`과 일치, 화면 사각형 환산.
- 실측: 방 선택 → 방 상세 → 건설 카드 → 상세 → 설치 → 미리보기 → 결제, 함정·시설·유닛 배치 같은 흐름, 수리·휴업·철거, 유닛 명령·이동·회수, 첫날 튜토리얼(방 짓기·유닛 배치·포탈)이 새 화면을 비추며 끝까지 진행되는지, 지도 클릭 차단.
