# 던전 FTL 연속 침입 3판

2026-11-06 방향 승인. 한 판의 방어 결과가 다음 판의 배치와 자원 선택에 영향을 주는 짧은 런을 먼저 만든다. 상위 기획은 [던전 FTL 전환 기획](DungeonFtlDesign.md)을 따른다.

## 진행

같은 1층 던전에서 **배치 → 침입 방어 → 결과 확인 → 다음 침입 준비**를 반복한다. 세 번째 침입 결과에서 짧은 런을 마친다. 전투 사이에는 심장 체력, 부하 체력, 금화를 이어간다. 금화를 심장 수리에 쓸지 함정 강화에 쓸지 결정한다. 마력 용량은 세 판 동안 3으로 유지한다.

| 침입 | 중심 위협 | 플레이어의 선택 |
|---|---|---|
| 1판 | 금고를 노리는 도적 | 금고에 부하를 남길지, 북쪽에서 적을 늦춰 함정에 모을지 고른다. |
| 2판 | 방을 부수는 공병 | 공병의 예고를 끊으려고 함정을 지금 쓸지, 뒤따라오는 적까지 기다릴지 고른다. |
| 3판 | 도적과 공병이 함께 오는 침입 | 금고와 방 시스템을 동시에 지키면서 심장까지 막는다. 앞선 두 판에 남긴 체력과 금화가 대응의 여지를 결정한다. |

예를 들어 첫 판에서 도적을 놓치면, 다음 준비에서 쓸 금화가 줄어든다. 남은 금화로 심장을 회복할지, 다음 공병을 상대할 함정을 강화할지 판단한다.

## 구현 순서

1. 전투 결과에서 심장 체력·부하 체력·금화를 다음 침입 준비에 넘긴다.
2. 세 침입의 구성을 연결하고 각 준비 화면에서 다음 위협을 보여 준다.
3. 전투 사이 심장 수리와 함정 강화 선택을 연결한다.
4. 노드 지도와 원정은 연속 침입 흐름을 만든 뒤 연결한다.

## 구현 전에 정할 것

- 각 판의 적 명단, 등장 순서와 간격
- 심장 수리 비용·회복량, 함정 강화 비용·효과·지속 범위
- 수리와 강화의 선택 횟수, 금화가 모자랄 때의 진행 방식
- 런 저장 시점과 이어하기 범위

## 연결 단계의 적용 기준

편성 데이터가 정해질 때까지 기존 침입 파티를 세 판에 재사용한다. 방어 성공 후 결과 띠의 다음 침입 버튼으로 배치 화면에 진입한다. 심장이 무너지거나 세 번째 방어가 끝나면 그 런을 종료한다.

쓰러진 부하는 런에서 제외한다. 방 내구와 고장 여부는 함께 이어간다. 수리 도중 내구가 일부 회복된 고장 방도 다음 판에서 고장 상태를 유지한다.

## 첫 침입 비교

### 실측 후 확정한 조정

- 도적은 입장 순서 맨 뒤로 옮긴다. 나머지 적의 상대 순서와 기존 입장 간격은 유지한다.
- 공병의 일반 시설 공격은 사거리 안에 교전할 부하가 없을 때 가능하다. 화약 폭파의 예고 조건과 피해를 받으면 끊기는 규칙은 유지한다.
- 도적이 입구 굴의 바깥 끝에 닿기 전에 처치되면 들고 있던 금화를 되찾는다.
- 재비교에서는 탈취 시작·회수 여부와 문 제어실 고장뿐 아니라, 북쪽과 함정 방 사이의 문이 잠금 기능을 유지했는지도 확인한다.

### 조정 후 실측

2026-11-06, 기존과 같은 마력과 함정 발동 기준으로 새 런 두 판을 비교했다. Unity 플레이 모드에서 0.05초씩 진행했다.

| 관찰값 | A. 금고 방어 | B. 북쪽 방어 |
|---|---|---|
| 승패 / 심장 체력 / 생존 부하 | 승리 / 30 / 3명 | 승리 / 30 / 2명 |
| 도적의 최대 보유 금화 / 종료 금고 잔액 | 0 / 150 | 0 / 150 |
| 첫 잠금 해제 시점 / 종료 시 잠금 | 8.00초 / 해제 | 10.00초 / 해제 |
| 종료 시 문 제어실 / 문 내구 | 고장 / 4 | 고장 / 2 |
| 전투 종료 | 17.35초 | 17.50초 |

북쪽 배치에서 잠금이 2초 더 유지됐지만 양쪽 모두 문 제어실이 고장 났다. 문 자체는 두 판 모두 파괴되지 않았다. 도적의 보유 금화가 두 판 모두 0이어서 탈취 후 회수는 이번 비교에서 관찰할 수 없었다.

### 도적의 교전 회피

도적이 금고로 가는 동안 다른 침입자를 공격하거나 공격 기술을 쓰고 있는 부하는 지나칠 수 있다. 해당 부하의 공격 판정은 그대로 적용된다. 금고 방의 부하, 교전 중이 아닌 부하, 도주 중인 도적의 교전과 문 잠금은 기존 규칙을 따른다.

### 조정 전 실측

기존 `DungeonRun`과 현재 첫 침입 편성으로 금고를 지키는 선택과 북쪽 방어에 힘을 싣는 선택을 비교한다. 결과 띠는 미회수 금화, 남은 심장 체력, 생존 부하 수를 표시한다. 미회수 금화는 전투 종료 시 침입자가 여전히 들고 있는 금화다. 처치해서 되찾은 금화와 처치 보상은 이 수치에 포함하지 않는다.

1. 매 비교는 새 런의 첫 준비 화면에서 시작한다. 마력은 두 판 모두 함정 2, 문 제어실 1로 맞추고 방패병 외 부하는 기본 위치에 둔다.
2. A에서는 방패병을 금고에 둔다. B에서는 방패병을 북쪽 문 제어실에 둔다.
3. 두 판 모두 첫 발동 가능 시점에 함정을 발동하고 이후에도 같은 기준을 따른다. 위기 멈춤에서는 함정 발동 예약을 제외한 추가 명령 없이 계속한다. 이렇게 시작 배치의 차이를 우선 살핀다.
4. 결과 띠의 미회수 금화, 심장 체력, 생존 부하 수와 방 이름판의 고장 여부를 기록한다. 승리 시 다음 침입 준비를 열어 금고 잔액과 심장 체력이 결과에서 이어지는지도 확인한다.

| 관찰값 | A. 금고 방어 | B. 북쪽 방어 |
|---|---|---|
| 승패 / 미회수 금화 | 승리 / 0 | 승리 / 0 |
| 심장 체력 / 생존 부하 수 | 30/30 / 3명 | 30/30 / 2명 |
| 고장 난 방 | 문 제어실 | 문 제어실 |
| 다음 준비의 심장 체력 / 금고 잔액 | 30 / 150 | 30 / 150 |
| 첫 함정 발동 / 전투 종료 | 9.10초 / 14.50초 | 10.85초 / 18.55초 |

2026-11-06 Unity 플레이 모드에서 씬의 배치·전투 메서드로 0.05초씩 진행했다. 두 판 모두 도적의 보유 금화가 전투 내내 0이었으며, 북쪽 배치에서 방패병이 추가로 쓰러졌다. 현재 편성에서 금고를 비워 치르는 금화 손실이나 북쪽 배치의 방어 이득은 측정되지 않았다. 실시간 조작감과 화면에서 느끼는 이동 판단은 별도 확인이 필요하다.

한 배치가 금화를 더 지키고 다른 배치가 심장·부하·방 상태 중 일부를 더 잘 보존하면 선택에 대가가 드러난다. 두 결과가 같거나 한 배치가 모든 항목에서 앞서면 현재 편성에서 상충하는 선택이 나타났다는 근거는 부족하다. 이 비교는 재미의 전제인 선택의 결과 차이를 보는 절차이며, 적 편성이나 밸런스 수치를 확정하는 절차는 별도로 남긴다.
