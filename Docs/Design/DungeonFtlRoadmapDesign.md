# 던전 FTL 전체 기획 로드맵

2026-11-06 초안. 기준은 [던전 FTL 전환 기획](DungeonFtlDesign.md)이다. [구현 설계](DungeonFtlImplementationDesign.md)의 이전 목업과 턴제 기록은 변경 이력으로 읽는다. 기획 공백을 결정하고 기획서를 갱신한 뒤 개발에 들어간다.

## 한 런에서 하는 일

고정된 던전에서 부하와 마력을 운영한다. 지도에서 위험과 보상을 보고 다음 칸을 고른다. 침입이면 내 던전을 지키고, 원정이면 전송 방으로 부하를 보내 상대 목표를 공격한다. 전투에서는 적 목표와 기술 예고를 보고 부하 이동, 마력 재배분, 함정 발동을 결정한다. 이후 남은 체력·부하·시설 상태·금화를 바탕으로 수리, 강화, 영입과 다음 경로를 고른다. 구역을 넘어갈 때 던전이 한 층 깊어지고 심장은 맨 아래로 이동한다. 마지막 공성전에서는 원정과 본진 방어가 동시에 일어난다. 런이 끝나면 성과에 따라 영구 강화 포인트를 받는다.

| 시점 | 플레이어가 판단할 것 | 이후에 남는 결과 |
|---|---|---|
| 지도 | 당장 필요한 보상을 좇을지, 다음 전투를 대비해 위험을 피할지 | 보상, 소모, 수배도 상승 |
| 배치 | 적이 노리는 방에 누구를 두고 어떤 장치를 켤지 | 전투 시작 위치와 사용 가능한 장치 |
| 전투 | 큰 기술을 끊을지, 부하를 뺄지, 함정을 기다릴지 | 심장·부하 체력, 시설 상태, 금화, 부하 사망 |
| 전투 이후 | 수리에 돈을 쓸지, 다음 판을 위해 강화할지 | 다음 전투의 전력과 쓸 수 있는 금화 |
| 원정 | 몇 명을 보내고 언제 후퇴할지 | 원정 보상과 본진에 남은 인원 |

## 현재 기준과 목표 범위

### 던전 FTL 게임 루프 (2026-11-09)

플레이어는 고정된 던전의 지휘관이다. 전투 전 배치로 첫 방어선을 만들고, 계획이 틀어지면 시간을 멈춰 부하와 방 마력을 다시 배치한다. 전투에서 지키거나 잃은 것이 다음 지도 선택의 근거가 된다.

| 범위 | 반복 흐름 | 다음 판단으로 넘어가는 것 |
|---|---|---|
| 전투 중 | 적의 목표와 예고 읽기 → 필요할 때 일시정지 → 부하 이동·마력 재배분·함정 발동 → 재개하고 결과 확인 | 새 위협, 부하의 위치와 체력, 방의 작동 상태 |
| 지도 한 칸 | 이전 손실 확인 → 갈 수 있는 칸의 위험과 혜택 비교 → 정비하거나 배치해 전투 → 결과 확인 | 심장·생존 부하·시설 상태·금화, 해당 런에서 얻은 강화 |
| 1구역 시연 런 | 도적 침입 → 상인 또는 글 사건 → 공병 침입 → 모험가 진지 원정 → 정예 침입 → 정산 | 승패와 남은 전력. 원정 승리의 추가 마력은 정예전에 사용한다. |
| 정식 런과 다음 런 | 구역을 진행하고 층을 확장 → 최종 공성 또는 패배 → 정산 → 영구 강화에 포인트 사용 | 다음 런의 시작 자원과 영구 능력치. 세부 보상과 강화 규칙은 기준 기획의 확정 범위를 따른다. |

### 시연판 작업 순서

1. **공병전의 첫 위기.** 현재 4초 예고에서 중앙 함정 방의 부하가 북쪽으로 이동해 유효타를 낼 수 있는지 확인한다. 같은 예고 상태에서 개입 없이 재개, 부하 투입, 위험한 부하 대피를 비교한다. 제시간에 끊을 수 있는 상황이 실제로 있어야 한다. 현재 수치로 성립하지 않으면 원인을 기록하고 조정 후보를 사용자에게 묻는다.
2. **위기 장면의 화면과 반응.** 공병전 준비 → 예고 → 대응 결과를 목업으로 확인한다. 위험한 방과 부하를 알아보고 명령 결과를 읽을 수 있는지 본다. [전투 화면 완성도 설계](DungeonFtlPresentationDesign.md)
3. **선택과 결과의 연결.** 지도 분기를 고르기 전에 현재 손실과 혜택을 읽을 수 있는지, 원정 결과가 정예전 준비에서 드러나는지 확인한다.
4. **시연 전체 흐름.** 타이틀부터 정산까지 첫 플레이에서 판단에 쓴 시간과 대기 시간을 따로 기록하고, 기존 완주 목표와 비교한다.

위 순서는 작업 제안이다. 첫 공병전의 기획 목표는 확정했고, 화면 변경과 전투 조정은 확인 결과를 바탕으로 범위를 정한다.

- **현재 구현**은 타이틀에서 시작·재개하는 1구역 시연 런이다. 1층 5방 십자 던전의 도적 침입부터 상인·글 사건 분기, 공병 침입, 모험가 진지 원정, 마지막 정예 침입과 정산까지 연결돼 있다. 첫 플레이 완주 시간은 미측정이다. [시연 런 상세 기획](DungeonFtlDemoRunDesign.md)
- **첫 시연판 확정 범위**는 1구역 완결형이다. 기존 1층 던전에서 지도 분기, 침입 방어, 대표 원정 1종, 구역 마지막 전투와 정산까지 경험한다. 3구역 확장과 왕국 공성 진지는 후속 목표다.
- **기존 최종 목표**는 8구역, 구역당 6~8칸, 던전 형태 3개, 부하 6종 안팎, 글 사건 100개 이상, 약 1시간의 런이다.

## 개발 순서 초안

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| 1. 연속 방어 | 1층 3판의 서로 다른 편성, 판 사이 수리·강화, 종료 정산 | 첫 판의 손실과 지출이 다음 판의 배치나 대응을 바꾼다 |
| 2. 지도와 자원 | 분기 지도, 수배도, 노드별 보상, 휴식·상점·사건·영입, 저장·이어하기 | 다음 칸을 고르는 이유가 보이며, 재개해도 선택과 결과가 보존된다 |
| 3. 대표 원정 | 원정 상대 1종, 목표, 파견·귀환·후퇴 | 파견 인원과 후퇴 시점에 따라 원정의 결과와 다음 방어에 남는 전력이 달라진다 |
| 4. 시연 런 완결 | 1구역 지도와 콘텐츠, 구역 마지막 전투, 승패 정산, 튜토리얼과 필요한 화면·아트·소리 | 타이틀에서 시작해 승리 또는 패배와 정산까지 이어진다 |
| 5. 3구역 확장 | 층 연결과 심장 이동, 층별 콘텐츠, 왕국 공성 진지 | 여러 층의 전력·부하 운용과 원정 중 본진 방어가 한 런에 이어진다 |
| 6. 정식 범위 확장 | 8구역, 던전 형태·사건·빌드 다양화, 난이도와 영구 성장 | 확정한 규칙으로 정식 런의 콘텐츠를 구성한다 |

순서는 의존 관계를 기준으로 제안했다. 시연판 세부 콘텐츠와 일정은 미정이다.

## 1구역 지도 흐름

완주 기준 10분 이상을 목표로 한다. 방어 3판과 원정 1판의 구간별 시간 예산은 [1구역 시연 런 기획](DungeonFtlDemoRunDesign.md)에 둔다.

**도적 침입 → 상인 또는 글 사건 → 공병 침입 → 필수 모험가 진지 원정 → 마지막 정예 침입 → 정산**

2026-11-06 사용자 승인. 모험가 진지 원정은 필수 경유이며 대장 처치가 승리 조건이다. 입구 굴을 출정·귀환 지점으로 쓰며, 후퇴·실패 시 원정 보상 없이 마지막 정예 침입으로 이어진다.

시연판은 고정 지도와 칸 단위 자동 저장을 쓴다. 상태 이월과 정산은 [시연 런 상세 기획](DungeonFtlDemoRunDesign.md)을 따른다. 수배도에 따른 지도 변화와 영구 강화는 후속 범위다.

## 개발 전에 확정할 항목

### 1구역 기획 검토안 (2026-11-09)

첫 검토 질문은 **이번 전투에서 감수한 손실 때문에 다음 전투의 배치나 마력 운용을 바꾸게 되는가?**다. 실시간 일시정지 전투와 고정 던전은 기존 시연판을 기준으로 삼는다.

- **지도 분기**는 같은 첫 침입 결과에서 상인과 글 사건을 각각 골랐을 때, 금화·심장 체력·부하 체력 차이가 공병 침입의 준비에 어떤 영향을 주는지 비교한다.
- **원정 결과**는 승리와 후퇴 경로에서 생존 부하와 마력 용량 차이가 마지막 정예 침입의 배치에 반영되는지 본다.
- **관찰 항목**은 선택 이유, 전투 전후 상태, 다음 전투에서 실제로 바꾼 명령, 첫 플레이 완주 시간이다. 기존 목표인 10분 이상과 대조하되, 준비·전투·지도에서 걸린 시간을 구분한다.

2026-11-09 사용자 결정으로 1구역 시연판을 먼저 다듬는다. 첫 검토는 지도 분기와 공병 침입을 묶어 진행한다. 이후 원정과 정예 침입으로 이어간다. [분기 비교 기준](DungeonFtlDemoRunDesign.md#상인과-글-사건-분기)

| 분야 | 남은 결정 |
|---|---|
| 시연 구성 | 글 사건 내용과 회복량 반올림, 각 칸에서 보여 줄 정보 |
| 방어와 전투 | 금고와 문 방어가 각각 주는 이득, 문 파괴와 수리, 전투 시간 종료 판정, 상성·방 보너스 등 임시 수치의 적용 범위 |
| 자원과 성장 | 상인 외 정비 기회의 유무, 금화가 모자라거나 부하를 잃은 상태에서의 진행 |
| 지도와 저장 | 시연 지도에서 표시할 정보, 후속 범위의 수배도 단계와 칸 변환·등장 비율 |
| 층과 방 | 방 담당 보너스, 시연판의 함정 교체·방벽·감옥 포함 여부, 후속 층의 방 배치·연결과 전력 경로 |
| 원정과 마지막 전투 | 진지 복도의 실제 길이, 대장·호위의 세부 수치, 후속 공성전의 동시 지휘와 해결 순서 |
| 콘텐츠와 마무리 | 부하별 스킬·역할, 적·정예 편성표, 사건·유물·상점 목록, 정산과 영구 강화, 튜토리얼, 아트·소리 목록 |

현재 확정된 규칙과 예전 후보가 함께 남은 부분은 해당 결정을 확정할 때 기준 기획서에서 정리한다. 예를 들어 현재 수동 함정과 마력 3칸은 연속 침입의 기준이며, 정식 런의 함정 교체와 마력 성장 방식은 별도 결정이다.

## 개발 시작 기준

시연판과 정식판의 범위, 런 시작부터 정산까지의 흐름, 각 시스템의 규칙·화면·데이터 목록, 개발 순서와 단계별 완료 기준을 먼저 합의한다. 수치가 확정되지 않았다면 사용자가 승인한 임시값과 나중에 조정할 값을 구분해 적는다. 기획을 검토하는 동안 구현과 테스트는 보류한다.
