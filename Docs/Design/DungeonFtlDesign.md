# 던전 FTL 전환 기획

2026-11-05 사용자 결정: 지금의 함정 본편은 타워 디펜스에 가깝다. FTL처럼 방 시스템·부하 배치·노드 지도로 진행하는 로그라이트로 바꾼다.
이 문서는 질문 8장(96문)과 후속 질문의 답을 정리한 것이다. 확정은 사용자가 고른 답이다. 수치와 세부 내용은 "미정"으로 남겼다.

- **상태(2026-11-06):** 1층 5방 십자 평면도(FTL 시점) 전투, 큰 기술 예고, 파티 카드·배치, 위기 자동 멈춤, 수동 함정, 전투 사이 상태 이월과 1구역 시연 런(타이틀 → 정산)을 구현했다. 시연 런 전체 플레이와 완주 시간은 미측정이다. 문서 안의 옛 결정은 지우지 않고 "바뀜"으로 표시한다.
- **기존 문서와의 관계:** 이전 기획 문서는 2026-11-05에 모두 지웠다(사용자 지시). 이 문서가 유일한 기획 기준이다.
- **작성 원칙:** 빈 곳이나 이해 안 되는 부분은 추론해서 채우지 않는다. 사용자에게 묻고, 답이 없으면 "미정"에 남긴다.
- **참고한 게임:**
  - FTL: 방 전력·선원·노드 지도·사건.
  - 엔드리스 던전(Dungeon of the Endless): 처치로 모으는 마력, 이어진 방에만 흐르는 전력.
  - 레전드 오브 키퍼스(Legend of Keepers): 함정 방·부하 방, 로그라이트 성장.
  - 로보토미 코퍼레이션: 옆에서 본 시설 단면, 복도를 걸어 다니다 마주치면 붙는 싸움, 직접 조종 없는 배치형 지휘.
  - 인투 더 브리치: 적 행동 미리보기(실시간 전환 뒤 어떻게 살릴지는 미정).
  - 산소 미포함: 방을 타고 퍼지는 생존 자원.

## 1. 게임 정체성

**전투 재미 우선순위 (2026-11-09 사용자 결정):** 던전 FTL의 중심은 계획이 틀어졌을 때 부하와 방 마력을 다시 배치해 수습하는 지휘다. 전투 전 배치는 위기를 맞는 출발 상태를 만든다. 전투 중에는 위협을 읽고, 일시정지에서 무엇을 지키고 무엇을 감수할지 결정하고, 재개해서 결과를 확인한다. 살아남은 부하와 남은 방 상태가 다음 칸의 선택으로 이어진다. 첫 검토 장면은 [공병의 폭파 위기](DungeonFtlDemoRunDesign.md)다.

| 항목 | 확정 |
|---|---|
| 던전 | 한자리에 **고정**. 지도 위를 움직이는 것은 시간과 부하 원정이다 |
| 상대 | **침입 방어와 원정 공격 둘 다**. 칸마다 다르다(침입 파티 / 모험가 진지 / 경쟁 던전 / 마을·사원) |
| 플레이어 | 직접 조종하는 캐릭터 **없음**. 방 마력, 부하 이동, 함정 발동을 지휘한다(함정 발동은 2026-11-05 추가) |
| FTL에서 가져올 것 | 방 전력 배분, 부하의 방 배치·이동, 노드 지도·글 사건·상점 |
| 화면 | **위에서 내려다본 평면도**(FTL 시점). 한 층은 5방 십자이고 층은 버튼으로 바꿔 본다(안 열린 층은 띄우지 않는다). 바뀜: 처음에는 "한 화면 단면도"였다(8장 "FTL 시점 전환"). 원정 때 내 던전과 상대 진지를 나란히 보는 방식은 공성전(후속)에서 다시 정한다 |
| 생존 자원 | **마력**은 심장에서 이어진 방에만 흐른다(엔드리스 던전 방식) |
| 함정 | **방 시스템의 하나(함정 방)**. 그림 대신 이펙트로 보여 준다. 아이템 그림은 함정으로 쓰지 않는다 |
| 시간 | **실시간 + 일시정지**(8장). 한때 턴제로 정했다가 2026-11-05 사용자 결정으로 FTL·로보토미식 실시간으로 되돌렸다 |
| 런 | 1시간 안팎. **로그라이트**: 실패하면 포인트로 영구 강화를 산다 |

## 2. 런 구조와 지도

- **연속 침입 3판(2026-11-06 방향 승인, 구현됨):** 같은 던전에서 심장 체력·부하 체력·금화를 넘기며 세 판을 막는다. [연속 침입 3판 설계](DungeonFtlThreeEncounterDesign.md)
  - 바뀜: 판 사이에 수리·강화를 고르는 메뉴는 두지 않는다. 시연 런에서는 지도 분기의 상인(심장 수리·함정 강화)과 글 사건(부하 회복)이 그 역할을 한다(7장 "첫 시연판 범위").

- **구역:** 최종 8구역이고 구역마다 6~8칸이다. 구역을 넘어갈 때 던전을 **한 층 더 파 내려간다**.
- **지도:** 구역마다 정해진 틀에 칸 내용을 무작위로 채운다. **칸마다 자동 저장**하며 되돌리기는 없다.
- **칸 종류:** 침입 방어, 원정 공격, 상인, 글 사건, 정예 전투, 휴식·수리, 부하 영입, 보물.
  - 휴식·수리 칸에서는 부하 전원 회복과 심장·방 수리 중 **하나를 고른다**.
- **글 사건:** 가진 부하·방에 따라 특별 선택지(FTL의 파란 선택지)가 생긴다. 사건 결과로 전투가 날 수 있다. 최종 목표는 100개 이상이다.
- **수배도(뒤에서 조여 오는 압박):**
  - 칸을 지날 때마다 조금씩 오르고 **내릴 수 없다**.
  - 높아지면 파티가 강해지고, 지도 칸이 침입 칸으로 바뀌어 가고, 처치 보상도 늘어난다.
- **보스:** 마지막 구역에만 **왕국 공성 진지** 하나가 있다. 진지를 원정으로 치는 동안 내 던전도 공격받는다. 이기면 엔딩을 보여 주고 런이 끝난다.

## 3. 던전·방·자원

### 핵심

- **심장(마력 핵):** 부서지면 패배한다. 새 층을 파면 항상 **맨 아래 층으로 내려간다**. 층이 깊어질수록 적이 지나야 할 방이 늘어난다.
- **금고:** 금고의 금화는 **곧 내 지갑**이다. 도적이 털어 도망치면 그만큼 쓸 금화가 준다. 출구 전에 잡으면 되찾는다.

### 재화

- **마력:** 동시에 켤 수 있는 **용량**이다(FTL 반응로 방식). 방에 넣어 두고, 빼면 돌려받는다. 현재 전투에서는 용량 3을 유지한다. 처치 즉시 증가를 없애고 전투 후 성장 선택은 연속 전투 단계에서 구현한다.
- **금화:** 처치·칸 보상·원정으로 얻는다. 상점, 수리, 방 레벨, 부하 강화에 쓴다.
- **강화 포인트(메타):** 런이 끝날 때 받는다(6장).

### 방

- **배치:** 층마다 **고정**이다. 한 층에 4~5방이고 모두 같은 크기다.
  - 1층은 심장·금고를 포함해 5방이다. 첫 시연판은 이 1층에서 진행한다.
- **한 층 모양(2026-11-05 확정):** 가운데 방과 동·서·남·북 방의 **5방 십자**이고, 위에서 내려다본다. 네 방향 복도는 모두 같고(길이 3, 임시) 싸움터다. 1층은 북 문 제어실·가운데 함정 방·서 치유 샘·동 금고·남 심장이며, 입구는 북 방 위 굴이다(8장 "십자 배치 전환", "FTL 시점 전환").
- **층 사이:** 층은 버튼으로 바꿔 본다. **층과 층을 잇는 방·통로는 미정**이다(2층을 만들 때 정한다). 전투 중 부하는 층을 오가지 못한다.
- **층 사이(이전 결정, 바뀜):** 아래 계단방 내용은 옆 단면 화면일 때의 결정이다. 십자 평면도로 바뀌며 효력을 잃었고, 남은 계단방 코드는 쓰지 않는다. **계단방**으로 오르내린다. 처음에는 "위아래로 맞닿은 방은 모두 이어짐(계단 방 없음)"이었으나 사용자 지시로 바꿨다.
  - 좌우는 복도로 이어지고, 위아래는 **계단방으로만** 오간다. 일반 방끼리는 위아래로 바로 이어지지 않는다(사용자 답 "1번으로 하자": 방마다 위아래 연결·섞기 안을 고르지 않음).
  - 계단방은 **길만 있는 방**이다. 시스템·마력이 없고 층당 4~5방에 세지 않는다. 사용자 말: "필요없다고 생각되면 빼도됌".
  - 한 층의 계단방 수와 자리는 **던전 형태마다** 다르다. 시연판 형태의 개수·자리는 미정.
  - 계단방을 여러 개 두어 층 사이 길이 고리를 이루게 한다(8장 "로보토미식 뒤엉킴").
- **방 종류:**

| 방 | 역할 |
|---|---|
| 심장 | 마력의 시작점. 부서지면 패배 |
| 금고 | 금화 보관. 도적의 목표 |
| 함정 방 | **수동 발동**(2026-11-05 확정, 8장 "마력 부족 유지·수동 함정"): 전력을 받는 동안 4초 충전하고, 플레이어가 발동하면 방 안 적 전원에게 피해를 준다. 안에 끼울 함정의 **교체**(상점·보상)는 정식판 결정이며 시연판 포함 여부는 미정 |
| 치유 샘 | 안에 있는 부하를 회복한다 |
| 마법 방벽 | **부하가 받는 피해**를 막는 횟수형 보호막. 마력 한 칸당 한 번 막고, 일정 시간 뒤 다시 찬다 |
| 문 제어실 | 마력이 있는 동안 문을 잠근다. 잠긴 문은 적이 쳐서 내구가 다하면 부서져 열린다 |
| 감시실 | 원정 상대 진지의 방 구성·적 위치를 보여 준다. 없으면 상대 진지가 가려져 있다 |
| 굴 감옥 | 감옥 방 안에서 쓰러뜨린 적은 죽지 않고 갇힌다. 구역을 넘어갈 때 몸값(금화)이나 마력으로 바뀐다. 부하로 돌리지는 않는다 |
| 전송 방 | 원정 부하를 상대 진지로 보내고 불러온다. 보낼 수 있는 인원은 전송 방 레벨만큼이다. 고장 나면 후퇴가 막힌다 |

- **방 작동 규칙:**
  - 마력이 들어가면 작동한다. 심장에서 이어진 길이 있어야 마력이 흐른다.
  - 부하가 안에 있으면 효과가 커진다(FTL의 담당 선원).
  - 공격받으면 **고장** 나고, 부하가 가서 고친다.
  - 금화로 **레벨**을 올린다. 레벨이 오르면 마력을 더 넣을 수 있다.

## 4. 부하

- **종류:** 6종 안팎이다. 지금 에셋의 **그림만 다시 쓰고 역할은 새로 짠다**(데이터 새로 작성).
- **개성 축:** 수리 속도, 방 운영 보너스, 전투 역할, 환경 내성.
- **인원 한도:** 바뀜: 처음에는 "방 하나당 1명(방 13개면 13명)"이었다. 2026-11-05 배치 규칙으로 **한 방에 여럿을 둘 수 있다**(8장 "할 일 분명하게"). 런 전체의 부하 수 한도는 미정이고, 시연판은 4명이다.
- **죽음:** 쓰러지면 그 런에서 **영원히 잃는다**. 부상 상태는 없다.
- **성장:**
  - 레벨업 때 스킬을 고른다.
  - 같은 방을 오래 맡으면 방 숙련이 붙는다.
  - 장비는 **2칸**이다.
  - 금화로 강화한다. 레벨업은 스킬을, 금화 강화는 능력치(체력·공격력)를 올린다.
- **얻는 법:** 부하 영입 칸과 글 사건으로만 얻는다. 상인 구매나 포로 전향은 없다.
- **시작:** 던전 형태마다 시작 부하·방 배치가 고정이다. 던전 형태는 3개이고, 나머지 둘은 업적 조건으로 열린다.
- **명령:** 방 단위로만 준다(부하를 고르고 방을 누르면 걸어간다). 싸움·수리는 자동이다.
- **아래 짝짓기 표와 적 표의 "앞줄·뒷줄":** 턴제 때의 말이다. 실시간에서는 근거리·원거리 역할로 읽는다. 방 안 자리를 어떻게 나눌지는 미정(8장).

### 부하 그림 짝짓기(2026-11-05 사용자 승인, 같은 날 그림 이름 정정)

처음 제안 때 데이터 파일 이름(Guardian·SlimeBlue·Shroom·Spider·Shade)을 그림 이름으로 잘못 불렀다. 실제 그림 이름으로 고쳤고, 사용자가 같은 짝짓기를 다시 승인했다. 슬라임에 붙였던 독·불 내성은 뺐다.

|---|---|---|---|---|
| 해골 방패병(GuardianUnitData) | 앞줄 탱커 | 마법 방벽 | 느림 | 포함 |

## 5. 적

### 침입 파티

- 2~5명 파티다. 칸과 수배도에 따라 인원이 달라진다.
- 침입 경로는 입구(북쪽 굴)가 기본이다. 처음 기획의 "공병은 벽을 뚫고 바로 들어온다"는 아직 구현하지 않았다. 지금 공병도 굴로 들어와 가장 가까운 켜진 방을 노린다. 벽 뚫기를 넣을지는 미정이다.
- 처치하면 마력과 금화를 준다.
- 정예 칸에는 강화 파티가 나온다.

### 적 직업 6종(지금 적 데이터의 그림을 그대로 쓴다)

| 직업 | 지금 데이터 | 노리는 것·역할 |
|---|---|---|
| 검사 | SwordEnemy | 앞줄. 심장으로 간다 |
| 궁수 | ArcherEnemy | 뒷줄 원거리 |
| 치유사 | HealterEnemy | 뒷줄에서 파티를 회복한다 |
| 도적 | ThiefEnemy | 금고를 털고 도망친다 |
| 공병 | SapperEnemy | 방 시스템을 부수고 벽을 뚫는다 |
| 견습 마법사 | ApprenticeMageEnemy | 마법 방벽을 깎고 광역 공격을 한다 |

- **정예 강화 파티:** 엘리트 방패병·궁수·치유사·정찰병 그림을 쓴다.
- **최종 보스(공성 진지)의 대장:** 기사단장(Boss_KnightCommander)을 쓴다.
- **남는 그림(오크·도적·인간·마을 주민 등):** 경쟁 던전의 부하와 마을·사원 주민에 쓴다.

### 원정

- 상대는 모험가 진지, 경쟁 던전, 마을·사원이다.
- 경쟁 던전은 **내 던전과 같은 규칙**으로 돌아간다. 상대도 마력으로 방 시스템을 켜고, 부하가 방을 고친다. 방을 부수면 상대가 약해진다.
- 승리 조건은 상대마다 다르다. 진지는 대장 처치, 경쟁 던전은 심장 파괴, 마을은 보물 방에서 일정 시간 버티기다.
- 부하는 전송 방으로 오가고 **언제든 후퇴**할 수 있다. 후퇴하면 보상이 없다.
- 원정 간 부하의 빈자리는 남은 부하와 방 시스템으로 막는다.

## 6. 보상·상점·메타

- **칸 보상:** 정해진 묶음이다(금화, 가끔 함정·유물).
- **유물:** **런 안에서만** 쓰고 장착 수 제한은 없다. 지금 본편의 영구 보유·2칸 장착은 쓰지 않는다.
- **상점:** 함정, 부하 장비, 수리·심장 회복, 유물을 판다.
- **등장 목록:** 부하·함정·유물은 첫 런부터 모두 나온다.
- **강화 포인트:**
  - 도달 구역과 성과(처치·원정 승리)로 얻는다.
  - 시작 자원과 영구 능력치에 쓴다.
- **난이도:** 쉬움·보통·어려움이다.

## 7. 화면·조작·범위

- **조작:** 마우스와 단축키(부하 선택·방 마력)다.
- **튜토리얼:** 타이틀에서 들어가는 **별도 튜토리얼 전투**를 둔다.
- **언어·소리:** 한국어만 쓴다. 소리는 새 방식에 맞게 **새로 구한다**.
- **에셋:** 사용자가 먼저 구해 온다. 부하·적은 지금 에셋을 쓴다. 구해야 할 것은 아래와 같다.
  - 단면도용 방·벽 타일
  - 방 시스템 그림(치유 샘·방벽·문 제어·감시·감옥·전송). 함정 방은 이펙트로 대신한다
  - 효과음·음악
- **일정:** 시연까지 **1달**이다.

### 첫 시연판 범위(이후 업데이트로 늘린다)

2026-11-06 사용자 승인. 1구역에서 지도 분기, 침입 방어, 대표 원정 1종, 구역 마지막 전투와 정산까지 이어진다. 3구역 확장과 왕국 공성 진지는 후속 목표다. 개발 단계와 미정 항목은 [전체 기획 로드맵](DungeonFtlRoadmapDesign.md)에 둔다.

- 시연판의 모험가 진지 원정은 필수 경유다. 원정의 승리 조건은 진지 대장 처치이며, 원정 중 후퇴할 수 있다.
- 시연판에서는 입구 굴을 출정·귀환에 쓴다. 원정에서 후퇴하거나 실패하면 원정 보상 없이 귀환한 생존자와 남은 자원으로 정예 침입을 이어간다.
- 후퇴를 명령받은 부하는 모험가 진지 입구까지 걸어 나가며, 이동 중에도 공격받을 수 있다. 입구에 도착해야 귀환한다.
- 진지 대장을 처치하면 살아 있는 파견 부하가 자동 귀환한다. 파견 부하가 전멸하면 원정 실패다. 별도 원정 제한 시간은 없다.
- 시연판에서 파견할 수 있는 부하는 최대 3명이다. 출정할 부하가 없으면 원정 실패로 처리하고 마지막 정예 침입 준비로 넘어간다.
- 시연판 모험가 진지는 검사와 궁수가 지키는 짧은 정면 길과, 궁수의 정면을 피하는 대신 입구까지 돌아가는 거리가 더 긴 우회로를 둔다.
- 첫 침입 뒤 분기에서 상인은 심장 수리와 함정 강화를, 글 사건은 부하 회복을 중심으로 한다.
- 구역 마지막 전투는 원정 이후 남은 전력으로 막는 정예 침입이다.
- 원정에서 승리하면 마지막 정예 침입의 마력 용량이 3에서 4로 오른다. 마지막 침입은 심장이 살아 있고 모든 적이 처치되거나 이탈하면 승리한다. 심장이 파괴되면 패배하며 시간 초과로 자동 승리하지 않는다.
- 첫 플레이 완주 기준 10분 이상을 목표로 도적 침입, 공병 침입, 마지막 정예 침입의 방어 3판과 원정 1판을 구성한다. [시연 런 상세 기획](DungeonFtlDemoRunDesign.md)

| 항목 | 시연판 | 최종 목표 |
|---|---|---|
| 구역 | 1구역 + 구역 마지막 전투 | 8구역 + 최종 보스 |
| 던전 형태 | 1개 | 3개 |
| 부하 | 4종 | 6종 안팎 |
| 적 | 시연 전투별 편성 미정 | 6종 안팎 |
| 글 사건 | 수량 미정 | 100개 이상 |

### 지금 본편 처리

- 새 방식은 **새 씬**에서 만든다.
- 함정 방은 이펙트로 대신하는 방식을 우선한다.
- 함정 본편(TrapCampaign)은 새 방식으로 옮긴 뒤 정리한다. 함정이 필요 없다고 판단되면 지워도 된다(사용자 허락).
- 지금 코드에서 무엇을 다시 쓸지는 구현 설계 때 사용자와 정한다.

## 8. 전투

2026-11-05 사용자 결정으로 **속도 순서 턴제를 버리고 실시간**으로 바꿨다. 사용자 말: "ftl이나 로보토미같은 시간 흐름을 원하고 조작은 거의 없는게 맞아 로보토미처럼 복도를 걸어다니면서 뒤엉키는걸 원하고 함정은 아직 잘 모르겠어". 아래는 그 뒤 제안을 사용자가 "추천 방식으로" 승인한 내용이다. 큰 틀은 **로보토미의 화면 움직임 + FTL의 지휘 방식**이다.

| 항목 | 확정 |
|---|---|
| 시간 | **계속 흐르는 실시간**. 스페이스로 언제든 멈추고, **멈춘 채로도 명령**을 내린다(FTL). 배속은 1배·2배 |
| 움직임 | 인물이 방과 복도를 **실제로 걸어 다닌다**(처음엔 옆 단면의 바닥선이었고, 지금은 위에서 본 평면도의 네 방향 복도). 적은 입구에서 들어와 목표(심장·금고)로 걷고, 부하와 **마주치면 그 자리에서 싸움**이 붙는다. 여러 무리가 복도·방에서 엇갈리며 뒤엉킨다 |
| 싸움 | **전부 자동**. 가까운 적을 치고, 스킬은 **초 단위 쿨**이 돌면 쓴다. 체력이 낮아진 부하는 알아서 물러나는 정도의 간단한 판단만 둔다 |
| 조작 | ① 부하를 고르고 방을 누르면 그 방으로 걸어간다 ② 방에 마력을 넣고 뺀다 ③ 일시정지·배속 ④ **함정 발동**(2026-11-05 추가, 멈춤 중에는 예약). 부하의 공격·스킬·대상 지정은 **없다**. 전투 전에는 배치 단계에서 부하와 마력을 놓는다 |
| 방어선 | 부하가 지키는 방에서 적이 **붙잡혀 싸운다**(복도는 미정). 부하를 어디 두고 언제 옮기느냐가 곧 전략이다 |
| 방 시스템 | 시간에 따라 **계속** 작동한다. 샘은 초마다 회복, 문은 마력이 있는 동안 잠금. 고장 난 방은 부하가 **걸어가서** 고친다 |
| 마력 배분 | 언제든(멈춘 상태 포함) 바꾼다. 바로 적용된다 |
| 함정 방 | **③ 직접 발동으로 확정**(2026-11-05, 아래 "마력 부족 유지·수동 함정"). 당시 후보: ① 자동 방 시스템 ② 부하가 다루는 장치 ③ 직접 발동. 1단계의 자동 함정은 임시였다 |
| 원정 중 침입 | 원정 전투와 내 던전 방어가 **같은 시간 흐름**에서 함께 돌아간다. 단, 시연판은 원정 동안 본진 전투가 없다(7장). 동시 진행은 공성전(후속)에서 만든다 |

### 실시간 전환으로 다시 정할 것(미정, 사용자에게 묻는다)

턴제 때 정한 답 중 실시간에서 뜻이 바뀌거나 빈 곳이 생긴 것이다. 추론으로 채우지 않는다.

**정한 것(2026-11-05 사용자 답):**
- **적 행동 미리보기:** 목표 방, 노리는 대상, 스킬 준비를 보여 준다.
- **방 안 자리:** 앞·뒤 줄을 없애고 **거리**로 바꾼다. 근거리는 붙어서, 원거리는 떨어져서 친다.
- **붙잡기:** 부하가 있는 방은 적이 **아무도 지나가지 못한다**(인원 제한 없음). 그 방 부하를 모두 쓰러뜨려야 지나간다.
- **층 사이 길:** 처음 답은 "맞닿은 방 모두 연결"이었으나 같은 날 **계단방**으로 바꿨다(3장).
- **화면(로보토미식):** 여러 층을 한 화면에 쌓아 보여 주고, UI 배치도 로보토미를 따른다(위 목표 막대, 오른쪽 위 시간 조작, 누른 인물·방은 작은 정보 창). 방 개수·크기·연결 규칙은 바꾸지 않고 그리는 방식만 바꾼다.
- **복도 싸움:** 복도에서 마주쳐도 **그 자리에서 싸움이 붙는다**.
- **교전 이탈:** 싸우는 중인 부하에게 이동 명령을 주면 **바로 빠진다**. 부하가 다 빠지면 적이 지나간다.
- **물러나기:** 체력이 일정 아래로 떨어진 부하는 **치유 샘으로** 물러난다. 샘이 꺼져 있거나 길이 막혔으면 물러나지 않는다. 끄고 켜는 조작은 없다.
- **자동 일시정지:** 없다. 스페이스로만 멈춘다.

**구조·전투 재설계(2026-11-05 사용자 답, 아래 "로보토미식 뒤엉킴"의 갈림길 안을 대신한다):**
- 사용자 말: "4방향으로 하되 층을 나눠서 층마다 기믹을 넣어서 챕터로 묶는게 좋을거같은데 그리고 전투가 너무 단순하지않아? 아예 의미가 없는 수준인거같은데".
- **층 모양:** 한 층은 **옆 단면 격자**다. 방이 여러 줄로 쌓여 상하좌우로 이어진다(로보토미 한 부서처럼). 층과 층은 **따로 떼어** 본다(한 화면에 쌓지 않는다).
- **챕터:** 챕터 = 구역이다. 구역을 넘을 때마다 **기믹이 있는 새 층**이 더해진다. 내 던전 전체를 지킨다.
- **전투 깊이:** **상성**(피해 종류와 내성), **방 시스템 중심**(마력이 모자라 싸우는 중에도 켜고 끌 판단이 계속 생기고 방 효과가 크다), **적 유형·패턴**(대응이 다른 적, 큰 기술 예고)을 더한다.
- **진행:** 질문으로 기획을 더 굳힌 뒤 목업을 그린다.
- **여러 층 동시:** 적 무리가 여러 층에 동시에 있을 수 있고, 플레이어는 **층 탭을 눌러 오간다**(로보토미의 부서 이동처럼).
- **격자 크기:** 한 층은 **2줄 × 2~3칸(4~5방 유지)**이다. 빈 칸은 복도나 바위로 둔다.
- **층 기믹 종류:** **환경 위험**(물이 차오름·독가스·천장 붕괴처럼 양쪽 모두에 영향), **층 전용 방 시스템**(그 층에만 있는 장치, 마력으로 다룬다), **층 규칙**(어둠·마력 절반·이동 느림처럼 층 전체에 걸린다). 층 전용 적은 고르지 않았다.
- **상성:** **3가지가 돌고 도는 관계**다(각자 하나에 강하고 하나에 약하다). **부하·적·함정 모두** 가진다. 이름과 짝은 미정.
- **마력 압박:** **용량 < 방 수(FTL식)**다. 여러 층의 방을 다 켤 마력이 없어, 적이 있는 층·방으로 마력을 옮겨 다닌다.
- **적 큰 기술 예고 대응:** **부하를 빼서 피하기**, **방 시스템으로 막기**(방벽·문 잠금·함정으로 끊거나 막기). 상성 맞는 부하 보내기는 고르지 않았다.
- **층 사이 부하 이동:** **전투 중에는 못 오간다.** 층 배치는 전투 전에 정하고, 싸우는 동안은 그 층 안에서만 움직인다.
- **적 침입로:** 입구는 1층 하나다. 무리마다 계단으로 내려가며 층마다 퍼진다. 앞 무리가 아래층에 있을 때 뒤 무리가 위층에 온다.
- **상성 이름:** **물리 → 마법 → 저주 → 물리**(물리는 마법에, 마법은 저주에, 저주는 물리에 강하다). 배율은 미정.
- **심장:** 지금대로 **맨 아래층**에 둔다.
- **시연판 층 기믹:** 1층은 **기믹 없음**이다. 사용자 말: "일단 1층부터 하고 2층가자". 2·3층 기믹은 1층을 만든 뒤 고른다(후보: 천장 붕괴·물 차오름·독가스, 회전 통로·용암 수문, 어둠·마력 약함·저주 땅).
- **상성 배율(임시):** 강할 때 1.5배, 약할 때 0.75배.
- **부하 상성(시연판):** 해골 방패병·해골 검사 물리, 해골 저격수 마법, 오크 주술사 저주. 공격과 몸이 같은 상성이다.
- **적 상성:** 같은 직업도 **파티마다 다르다.** 정하는 방식과 보여 주는 시점은 미정.
- **큰 기술 예고(시연판):**
  - 공병 · 화약 폭파: 방 하나에 폭약을 놓고, 몇 초 뒤 방 안 전원(양쪽)과 방 시스템에 큰 피해를 준다.

- 폭파는 현재 방에 부하 또는 정상 시스템이 있을 때 시작한다. 2026-11-09 사용자 결정: 공병은 그 방 부하를 무시하고 방 가운데까지 걸어가 폭약을 놓은 뒤 예고를 시작한다. 같은 날 사용자 결정: 폭파·화염구를 예고 중인 시전자가 있는 방으로 이동 명령을 받은 부하는 길의 적을 지나쳐 걷고, 시전자가 사거리에 들면 평타·스킬 모두 시전자를 먼저 친다. 이렇게 적을 지나친 부하는 그 뒤 새 이동 명령을 받으면 길의 적을 다시 지나쳐 돌아오고, 도착하면 지나치기가 끝난다. 돌진은 예고를 시작할 때 경로에 잠겨 있던 문을 기억해, 발동 전에 문이 풀려도 그 문 앞에서 멈춘다. 시스템 피해 8에는 공병의 기본 방 공격 2배를 중복 적용하지 않는다.
- 나머지는 기존 공격 거리 안에 유효 대상이 있을 때 시작한다. 화염구는 목표 방을, 사격은 부하 하나를, 돌진은 그 부하 쪽 일자 경로를 시작 때 고정한다.
- 폭파·화염구는 시전자 실제 체력이 1 이상 깎이면 취소된다. 방어로 피해를 전부 막았으면 취소되지 않는다. 함정도 같은 피해 경로로 예고를 끊는다.
- 화염구는 예고 시작 때의 최단 경로를 고정하며, 그 경로에 잠긴 문이 있거나 생기면 즉시 취소한다. 다른 우회로로 바꾸지 않는다.
- 돌진은 시작 위치부터 대상 방향의 같은 동서 또는 남북 일자 줄 방·복도 끝까지다. 굴로 연장하지 않는다. 예고 종료 순간 경로 끝으로 이동하며, 잠긴 문이 있으면 문 앞에서 멈춘다. 문 뒤와 다른 줄·진행 방향 뒤쪽 부하는 맞지 않는다.
- 사격 대상이 처음 방을 나갔거나 발동 순간 사거리 밖이면 빗나간다. 다른 부하로 대상을 바꾸지 않는다. 마법 방벽 대응은 후속 단계다.
- 폭파 외 기술은 부하에게만 피해를 준다. 화염구는 시전자의 몸 상성과 무관하게 마법이며, 나머지는 시전자 상성을 쓴다. 기존 상성 배율·올림·방어 감소 순서를 따른다.
- 모든 예고는 시전자 사망·퇴장 또는 전투 종료 때 사라진다. 폭파·화염구 외에는 죽지 않는 한 일반 피해만으로 취소되지 않는다.
- 궁수에게 예고 사격을 연결하고 부하 저격수의 즉시 조준 사격은 유지한다. 현재 파티는 검사·궁수·도적·공병 뒤에 마법 상성 견습 마법사를 추가한 5명이다.
- 2단계는 규칙·데이터·테스트다. 예고 빗금·초읽기 원은 3단계에서 만든다. 마법 방벽 방·층 기믹·층 사이 이동은 이번에 만들지 않는다.

**로보토미식 뒤엉킴(2026-11-05 실측 뒤 사용자 답, 이전 기록):** 첫 실시간 판은 입구에서 심장까지 한 줄 길이라 라인 디펜스처럼 됐다. 그래서 아래를 정했다.
- **갈림길:** 층 사이 **계단방을 여러 개**(예: 양 끝) 두어 길이 고리를 이룬다. 입구가 층 가운데에 있으면 적이 양쪽으로 갈라질 수 있다.
- **적 흩어짐:** 파티가 **목표별로 갈라진다.** 도적은 금고, 공병은 방 시스템, 나머지는 심장으로 간다.
- **길 고르기:** 가장 짧은 길로 가되, **막힌 길을 피해 돌아간다.** 부하가 지키는 방·잠긴 문이 있는 길보다 돌아가는 길이 나으면 돌아간다. 부하 배치가 적의 길을 바꾼다. "막힘"을 얼마로 칠지는 미정.
- **미정:** 공병이 노리는 방 시스템을 어떻게 고르는지(가까운 방 등). 근접 부하가 손이 닿지 않는 원거리 적을 어떻게 상대하는지(사용자가 "같은 방 + 나를 치는 적에게 다가가고, 끝나면 자리로 돌아감"을 골랐으나, 로보토미식 재검토로 반영을 멈췄다).
- **1단계 배치:** 이 답에 맞춘 배치 안을 목업으로 보여 드리고 고른다(미정).

## 미정(사용자에게 물을 것)

추론해서 채우지 않는다. 해당 작업에 들어가기 전에 사용자에게 묻는다.

- **수치:** 심장 체력, 금고 털림 양, 마력 획득량·방별 필요량, 방 레벨 비용과 효과, 수배도 상승 폭과 단계별 효과, 메타 강화 비용, 전송 방 레벨별 인원, 방벽이 다시 차는 시간, 잠긴 문 내구, 오래 끈 전투가 끝나는 시간, 이동 속도·스킬 쿨(초).
