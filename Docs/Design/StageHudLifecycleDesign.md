## 확인한 경로

콘솔의 StageHudView.OnEnable:65 예외는 Awake에서만 생성하던 StageBattleSignals의 인스턴스 메서드를 이벤트에 연결하는 위치다. OnEnable에 런타임 캐시 복구가 없고 다른 표시/입력 도구도 같은 생성 순서에 의존한다. 편성 행 Bind는 기존 콜백을 해제하지 않으며, 경로/궁극기/적 표식/장치가 만든 루트는 HUD가 함께 정리하지 않는다.

## 처리 순서

- Awake와 OnEnable에서 EnsureRuntimeState를 사용한다. OnEnable은 이전 구독 해제 → 누락된 도구 복구 → 이벤트/버튼 연결 → 편성 행 연결/표시 갱신 순서다. 일반 재활성화에서는 살아 있는 기존 도구와 배치 선택을 유지한다.
- 세션 이벤트는 HUD 인스턴스의 고정 처리 메서드에 연결하고 그 안에서 표시 도구에 전달한다. 도구 생성 전의 인스턴스 메서드로 델리게이트를 만드는 경로를 제거한다. 연결/해제는 반복해도 같은 소유자의 런타임 콜백 하나만 남긴다.
- 생성한 월드 표식 루트는 직렬화된 숨김 참조 visualRoot로 소유한다. 세션 아래 월드 변환을 유지해 캔버스 배율의 영향을 피하고, 각 도구 루트를 그 아래 둔다. 관리 캐시가 유실되면 추적 중인 기존 루트를 비활성화/정리한 뒤 새 도구를 만든다. 이름 검색/Find/정적 캐시를 추가하지 않는다.
- 비활성화 시 도구 알림/커서를 숨기고 표식 묶음 전체를 비활성화한다. 종료 시 추적 루트를 정리한다. 루트/참조가 먼저 파괴됐거나 Awake 전인 해제 경로도 허용한다. 표시 도구는 루트 유효 상태와 파괴된 표시의 숨김 처리를 확인한다.
- 편성 행 Bind와 OnEnable은 기존 콜백 해제 후 연결하고 OnDisable/OnDestroy/HUD 비활성화에서 해제한다. 재바인딩과 독립적인 행 재활성화를 모두 지원하고, HUD 비활성 상태에서 행 입력을 처리하지 않는다.
- 안내 글자의 원래 크기는 재활성화/표시 도구 복구 때 결과 자동 맞춤 크기로 다시 덮지 않는다. 런타임 캐시가 없으면 기존 TMP 자동 맞춤 상한에서 복구한다.

화면 배치·색·텍스트 크기 기준과 전투/배치·저장/보상·밸런스 규칙은 유지한다. 이 작업은 HUD의 초기화/해제 범위이며 StageSession 등 게임 전체 상태의 재로드 복원을 구현하는 것은 아니다. 씬/프리팹/YAML·사용자 저장 파일은 수정하지 않는다.
