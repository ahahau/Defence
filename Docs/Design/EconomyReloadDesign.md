# 경제 상태의 스크립트 재로드 보존

2026-10-26 사용자 승인 범위. 실행 중 어셈블리 재로드에서 CostManager의 readonly 비직렬화 장부가 새로 생성돼 금화·부채가 0이 되는 경로를 수정한다.

- 금화·부채 장부는 Unity가 보존할 수 있는 숨긴 직렬화 필드로 둔다. 최초 Awake는 기존 initialGold로 시작하고 OnEnable은 장부·계약을 초기화하지 않는다. 잔고가 0인 경우도 정상 상태다.
- CostManager.Current를 OnEnable에서 복구한다. 정산 일차와 중복 청산·계약 차감 판정에 필요한 DayManager.Current도 같은 생명주기로 복구한다. 중복 인스턴스는 기존처럼 거절한다.
- 할인·신용 경고·오늘 한도 초과·계약 주수·상품·정산 이연·마지막 청산/계약 일차는 재로드 전후 동일해야 한다. 기존 계산식과 체크포인트 JSON은 바꾸지 않는다.
- 저장 파일에서 옛 체크포인트를 다시 읽어 재로드를 복구하지 않는다. 저장 뒤 아직 정산되지 않은 변화를 되돌릴 수 있기 때문이다.
- Unity 직렬화 왕복, 잔고 0 보존, Awake 없는 OnEnable, 동일 일차 중복 청산·계약 차감 회귀와 실제 RequestScriptReload 전후 수치를 검사한다. 게임 전체 런타임 상태의 재로드 지원을 뜻하지 않는다.
