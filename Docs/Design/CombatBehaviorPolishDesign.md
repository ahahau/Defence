# 전투 BT 동작 보완

2026-10-26. 사용자 승인: 치고 빠지기 연결과 역할별 전술을 모두 다듬는다.

## 현재 구조

`UnitBT`와 `EnemyBT`의 역할 분기는 유지한다. 공통 교전은 `EngageTargetAction`, 적 원거리의 치고 빠지기는 `SkirmishTargetAction`을 쓴다. 지원의 주기 회복은 `BattleAgent.TickSupportAura`가 담당한다.

## 행동

- 치고 빠지기는 대상을 새로 잡으면 접근부터 시작한다. 공격 중 사거리 밖으로 나가면 공격 구간을 중단하고 재접근한다. 후퇴 도중 대상이 사거리 밖으로 나가면 더 멀어지지 않고 재접근한다.
- 공격 예비 동작·피격 경직 중에는 단계 타이머도 기다린다. 속박은 기존대로 이동만 막고 공격은 허용한다. 현재 공격 대상이 유효하면 휘두르는 도중 점수 비교로 다른 적을 고르지 않는다. 사망·퇴장한 대상은 즉시 해제하고 명시적 도발은 기존대로 우선한다.
- 근접은 기존 사거리·회복 걸음을 유지한다. 탱커의 Frontline 선택은 같은 방의 후열 아군을 공격하는 적에 우선 가중치 20을 준다. 기존 전열 가중치 차이 12보다 높아 후열 위협을 먼저 막고, 위협끼리는 기존 점수로 고른다. 수치는 `CombatMoveRules`에 둔다.
- 원거리 치고 빠지기도 공격 구간에서 기존 `MaintainRange`를 사용한다. 발사 직후 정지·카이팅 속도·공격 간격은 유지한다.
- 지원은 같은 방의 살아 있고 순회 중이 아닌 부상 아군을 우선한다. 체력 비율이 가장 낮은 아군에게 치유 범위의 90% 안쪽까지 합류하고, 치유 범위 안에서는 적을 쫓아 나가지 않는다. 적이 사거리에 있으면 공격하고, 없으면 공격을 멈추고 지원 위치를 유지한다. 주기·회복량을 추가하지 않아 이동 때문에 회복 횟수가 늘어나지 않는다. 지원 대상이 없으면 기존 교전으로 돌아간다.

## 이동과 좌우 방향 조건 재정리 (2026-10-26 후속 승인)

| 상태 | 방향 |
|---|---|
| 순회·접근·돌진·지원 합류·재집결·엄호 위치 이동 | 실제 자발적 이동 스텝의 가로 방향 |
| 공격·카이팅·뒷걸음·넉백 | 유효한 전투 대상 방향 |
| 정지·가로 이동이 없는 수직 이동·대상과 거의 겹침 | 현재 방향 유지 |
| 순간이동·즉시 대시 | 이번 이동으로 방향을 바꾸지 않고 이동 추적 초기화 |

- 방향 제어는 활성 BattleAgent의 이동 후 판단 한 곳으로 모은다. EntityRender는 방향 적용(Y 0/180)과 애니메이션을 담당하고, BattleAgent가 없거나 비활성이면 기존 이동 방향 추적을 사용한다.
- 자발적 이동은 클램프 후 실제 스텝을 기록한다. 겹침 해소·넉백을 걷기로 세지 않는다. 근접 휘두르기 거리 안의 접근, 공격 예비 동작·피격 중에는 대상 방향이 우선한다.
- 기존 이동 임계 속도 0.3u/s, 평활 0.12초·이동 방향 전환 유지 0.2초, 대상 가로 차이 0.1u 기준을 유지한다. 멈추거나 방향 모드가 바뀌면 지난 이동의 평활값을 버린다. 수직 이동에 남은 가로 속도로 뒤집지 않는다.
- Face의 비주얼 자세 복원은 별도 비주얼 자식에만 적용하고 루트 위치·회전·크기를 복원하지 않는다. 순간이동 시 애니메이션 이동 추적도 초기화해 이동 직후 걷는 동작이 남지 않게 한다.

그래프 에셋·역할·스탯·사거리·치유량·저장 형식은 변경하지 않는다. 방향은 위 후속 승인 표를 기준으로 하고 기존 이동 잠금은 유지한다. EditMode에서 단계 전환·잠금·대상 고정·탱커 위협 선택·지원 이동과 회복량 보존을 검사하고, Unity 플레이에서 실제 컴포넌트와 BT 노드로 동작을 확인한다.

## 2026-10-26 노드 이동·선택·BT 보완 승인

- 엄호와 아군 재집결도 방 칸 경로를 따른다. 목표가 방 밖·막힌 칸이면 가까운 통행 가능 칸을 목적지로 잡는다. 지원 합류는 기존 우회를 유지한다. 방 크기·통로·확장비·저장 형식은 유지한다.
- 생성된 방의 선택은 실제 바닥 칸을 따른다. 기둥·깎인 모서리·복도의 빈 지점은 방 클릭으로 취급하지 않는다. 설치된 시설·칸막이는 원래 바닥이면 관리할 수 있다. 모양 없는 옛 노드는 기존 클릭 축소 범위를 유지한다. 전투 트리거 크기는 바꾸지 않는다.
- 선택 격자 외곽은 사각 틀 대신 열린 칸과 막힌 칸이 맞닿는 경계를 이어 그린다. 기존 내부 격자·시설 슬롯 색을 유지한다.
- 돌진 성공은 대상이 사거리 안에 들어온 때만 반환한다. 엄호·재집결·스트레이프의 시간은 이동 잠금 동안 기다리고, 치고 빠지기의 후퇴도 속박 중 기다린다. 공격 단계와 도발은 이동만 막는 속박 때문에 중지하지 않는다. 예비 동작·피격 중 도발 타이머도 기다린다.
