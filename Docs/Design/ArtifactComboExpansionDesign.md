# 유물 조합 콘텐츠 확장 설계

2026-10-27. 사용자 요청: 유물 조합 콘텐츠와 연속 선택 사건을 순서대로 진행한다. 아래 범위를 승인받아 구현했다.

## 확인한 현재 구조

- ArtifactComboCatalog.asset에는 기존 조합6개가 있다.
- 조합은 두 유물을 모두 보유할 때 자동으로 적용된다. 여러 조합이 동시에 성립하며, 특정 조합을 장착하거나 하나만 고르는 시스템은 아니다.
- 조합별로 모든 유닛/고용 유닛/메인 유닛 대상과 공격력·최대 체력·공격 간격을 설정할 수 있다. 현재 조합 데이터로 경제 수입·고용가 같은 운영 효과를 만들 수는 없다.
- 상점은 조합 상대와 효과를 표시하는 기존 경로가 있다. 신규 유물이나 상점 진열 수를 늘리지 않고 기존 유물의 짝을 추가한다.

## 추가할 조합3개

| 이름 | 유물 두 개 | 추가 대상·효과 | 의도 |
|---|---|---|---|
| 야전 의료 체계 | 야전 의무낭 + 병참 장부 | 모든 유닛 최대 체력 +10 | 의무낭과 장부를 함께 모으는 생존 조합 |
| 기동 보급대 | 야전 의무낭 + 척후병 장화 | 고용 유닛 최대 체력 +6, 공격 간격 ×0.94 | 장화의 체력 부담을 보완하며 공격 주기를 단축 |
| 친위대의 맹세 | 대장의 인장 + 탑 방패 | 메인 유닛 공격력 +2, 최대 체력 +12, 공격 간격 ×1.05 | 메인 유닛 생존·화력과 공격 주기의 교환 |

표의 값은 각 유물 기본 효과에 추가되는 조합 효과다. 기존 조합들과도 누적된다. 기존6개 조합·유물 가격/개별 효과·상인 주기/진열 개수는 유지한다. 신규값은 이 콘텐츠 추가의 제안값이며 장시간 밸런스 튜닝을 하지 않는다.

## 구현 범위

Unity CLI의 Editor API로 ArtifactComboCatalog.asset의 목록 끝에3개를 추가한다. 설명은 적용 대상과 실제 수치를 포함한다. 기존 런타임과 UI 표시를 사용하며 새 C# 효과 클래스·새 아이콘·새 유물·씬 연결은 필요 없다. 런타임 보유 목록 SO는 수정하지 않는다.

최소 확인은 기존6개 보존·새 짝 중복 없음·양쪽 유물 존재/판매 목록 포함·조합 대상/수치 및 양방향 상대 조회다. Sequences.md에 결과를 기록한다.

## 구현 결과

- ArtifactComboCatalog.asset은6개에서9개로 확장했다. 기존6개와 유물/상점 에셋은 유지한다.
