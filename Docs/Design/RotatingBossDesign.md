# 순환 보스의 금고 방어 전환

2026-10-28 개정. [종합 기획](../DungeonEconomyDesign.md) · [전환 설계](TreasuryDefenseDesign.md) · [문서 목록](README.md).

> 상태: 새 방향의 적용 방침이다. 2026-11-02 기준 StageDefense는 7개 스테이지 마지막 웨이브에 서로 다른 보스와 호위를 둔다([고정 스테이지 구현](StageRuntimeImplementationDesign.md) "보스 웨이브"). 아래 일차 순환·특수 패배는 보존된 SampleScene 경로다. 세부 기준안·수치는 종합 기획의 승인 상태를 따른다. 테스트·플레이·프리뷰를 실행하지 않는다.

## 목표

보스는 반복 방어에서 특별한 배치 대응을 요구하는 침입 웨이브로 남기는 안이다. 청산일 채무·별도 시간 초과·부하 손실 수에 의한 즉시 패배를 계속 늘리지 않는다.

## 재사용 대상

대마법사·오크 대족장·기마 두목과 호위/증원, 기존 외형·애니메이션·스킬·배너는 보존한다. 보스도 메인 금고를 목표로 전진하며 경비와 교전하는 공통 흐름을 사용하도록 전환한다.

## 보류 사항

- 현재 구현에는 7일 간격, 1~28일 보스 정의, 35/42/49일 순환과 바퀴별 배율이 있다. 이는 현행 구현값이며 새 진행 주기를 자동 확정하지 않는다.
- 보스의 도달 피해·호위 구성·반복 난도·최종 단계·부하 부활 허용 여부는 별도 결정 전 수치를 바꾸지 않는다.
- 금고 방 진입 즉시 패배와 실제 도달 피해는 다르다. 새 도달 규칙을 정하면 기존 loseOnTreasuryBreach 등 패배 판정을 함께 전환해야 한다.
- 이전 플레이 기록과 일부 중단된 실측은 아카이브의 과거 결과다. 새 금고 방어 버전의 완료/검증 근거로 사용하지 않는다.
