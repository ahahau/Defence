## 밀치기 경로의 함정 연계 (2026-11-03)

함정 중심 본편의 후속 보완으로 수동 밀치기의 출발점→안전한 도착점 사이도 기존 함정 접촉 경로를 거친다. StageForcedMovement는 기존 지형/점유 검사로 정한 구간을 1/8칸 이하 간격으로 이동하며, StageSession에서 전달한 CheckTraps를 각 위치에 호출한다. 같은 함정 안에서는 EnterTrap이 재굴림을 막고, 빈 칸을 거쳐 다른 함정에 들어가면 기존 발동 확률·기동성·재사용·피해 규칙을 사용한다. 미리보기/발동 가능 조회는 접촉을 발생시키지 않는다.

도중 함정 피해로 쓰러진 적은 즉시 이동을 멈춘다. 이미 끝난 적을 도착점으로 다시 옮기거나 처치/보상을 별도로 처리하지 않는다. 위험 지형은 기존 주기 피해를 유지하며 순간 이동 중 체류 시간을 새로 만들지 않는다. 자발적 이동과 기존 스킬 이동, 씬·에셋·피해 수치·저장 형식은 바꾸지 않는다. 이하 기존 접촉 보정의 선분 검사 제외는 일반 이동에 대한 과거 범위이며 이번 수동 밀치기는 별도로 보완한다.

함정/장치 피해의 처치 알림으로 HUD가 발동 가능 여부를 다시 조회해도 현재 발동 중인 대상 목록이 바뀌지 않게 조회 목록을 분리한다. 낙석·불 구멍·위험 지형 피해에도 같은 보호를 적용한다.

구현 확인: Runtime/Editor/Tests 빌드·Unity 재컴파일·현재 콘솔 오류 0. 이동 경로·도중 처치·문 차단·조회 재진입의 회귀 검사 4개는 작성/컴파일만 했으며 테스트 실행과 플레이 검증은 하지 않았다.

## 지속 함정의 마지막 발동 보장 (2026-11-03)

내구도 소모로 지속 함정이 파괴될 마지막 발동에서는 그 소모를 지속 효과 종료까지 미룬다. 작동 중에는 재발동하지 않으며 효과가 끝나면 소모를 한 번 적용해 기존 파괴 경로로 정리한다. 공병 해체·외부 피해·플레이어 철거는 기존 즉시 중단을 유지한다. 마지막이 아닌 발동의 내구도 소모 시점도 유지한다. 공통 Trap 처리이므로 구 SampleScene의 지속 함정에도 적용한다.

스테이지 준비 저장에는 선택 필드 pendingWear(대기 중인 마지막 소모량)를 추가해 남은 지속시간과 함께 보존한다. 없는 구 저장은 0으로 읽어 이미 지불한 소모를 다시 적용하지 않는다. 복원 전에는 지속형/남은 작동시간/실제 소모량/남은 내구도를 대조한다. 파일 버전과 기존 필드 의미는 유지하고 사용자 저장 파일을 직접 변경하지 않는다. 피해·발동 확률·지속시간·재사용 수치와 씬·프리팹·SO는 바꾸지 않는다.

구 런은 함정 지속시간을 저장하지 않으므로 마지막 소모를 기다리는 함정을 CaptureBuilding에서 제외한다. 소진한 함정이 이어하기로 재생성되는 것을 막는 한정 보완이며 구 런 파일 형식·복원 순서는 바꾸지 않는다.

검증: Runtime/Editor 빌드·연결 Unity 재컴파일·콘솔 오류 0. 마지막 발동·해체·준비 저장 후 복원은 테스트/플레이/저장 왕복 금지로 실측하지 않았다.
