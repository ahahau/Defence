# 시설 대기열 설계

## 목표

시설 노드는 일반 노드처럼 한 파티가 점유해 잠기지 않는다. 대신 각 시설은 독립적인 이용 정원과 FIFO 대기열을 가지며, 손님은 도착한 순서대로 이용한다.

## 동작

- `Building.maxConcurrentVisitors`는 동시 이용 수이며 기본값은 1이다.
- 시설에 도착한 모험가는 자리가 있으면 즉시 이용하고, 없으면 같은 방에서 대기한다.
- 이용 종료·사망·시설 폐쇄 시 모험가는 자신의 이용 또는 대기 상태를 해제한다.
- 다음 대기자는 자신의 순회 틱에서 자리가 난 것을 확인한 뒤 이용을 시작한다.

## 범위와 검증

기존 시설 수입·마모·목적지 규칙은 유지한다. 일반 노드 점유와 전투 정원은 바꾸지 않는다. EditMode에서 FIFO, 동시 이용 한도, 취소 뒤 다음 손님 진입을 검증하고 Unity CLI가 복구되면 실제 플레이 흐름도 확인한다.
