# 던전 FTL 전투 화면 완성도 설계

2026-11-09 검토안. [기준 기획](DungeonFtlDesign.md)과 [기존 승인 화면](DungeonFtlImplementationDesign.md)의 위에서 보는 5방 십자, 배치 화면, 위기 자동 멈춤, 장부형 HUD를 출발점으로 삼는다.

## 첫 목업 범위

공병 침입 하나를 **준비 → 첫 폭파 예고 → 대응 결과** 세 장면으로 보여 준다. 같은 던전과 HUD를 세 장면에 이어 써서 배치한 부하가 어디에서 싸우고, 위험이 어느 방에 생겼으며, 내가 내린 명령으로 무엇이 달라졌는지 따라갈 수 있게 한다.

| 장면 | 가장 먼저 보여 줄 것 | 화면과 연출 후보 |
|---|---|---|
| 준비 | 입구에서 문 제어실을 지나 함정 방으로 이어지는 길 | 방·복도에 공통 석재를 쓰고, 문·치유 샘·금고·심장은 방의 용도를 드러내는 실루엣으로 구분한다. 함정 방은 바닥에 들어간 장치와 발동 이펙트로 표현한다. |
| 첫 폭파 예고 | 공병, 대상 방, 남은 시간 | 북쪽 문 제어실과 부하를 가리지 않는 위기 카드, 방 안 폭파 범위, 이동 명령을 내렸을 때의 목적지 표시를 한 화면에서 검토한다. |
| 대응 결과 | 실제 폭발 또는 예고가 중단된 이유 | 폭발은 해당 방에서 섬광·파편으로 짧게 보여 주고, 방의 정상·고장 상태는 이후에도 구분한다. 예고가 중단되면 중단된 위치에 짧은 표시를 남기는 안을 검토한다. |

### 결정: 공병 폭파 표시 (2026-11-12 사용자 승인)

- 대상 방 안 아래쪽의 한 줄 표시에 방 이름과 실시간 초읽기를 함께 넣는다. 예: `함정 방 폭파 · 3.2초`. 화면 알림도 `공병 · 함정 방 폭파 4.0초`처럼 방 이름을 쓴다.
- 예고가 끝나면 같은 위치에 `폭파 차단` 또는 `폭파 발동`을 기존 결과 표시 시간 동안 보여 준다. 전투 종료로 예고가 지워지면 폭파 결과는 표시하지 않는다.
- 기존 위험 범위 빗금과 수동 일시정지를 사용한다.

## 먼저 다듬을 방향

1. **던전이 실제 장소처럼 보이게 (추천)**  
   현재 방 몸체와 테두리는 기본 도형으로 그린다. 첫 목업은 석재 바닥·벽, 연결되는 복도, 문과 심장부터 잡는다. 방의 상태나 인물보다 배경이 먼저 튀지 않도록 명암을 제한한다.
2. **명령과 전투 결과가 선명하게**  
   기존 배경에서 부하 선택·이동, 공병 예고, 폭발과 고장 표시를 먼저 다듬는다. 화면을 가리지 않는 범위에서 입력 직후와 결과 직후를 구분해 보여 준다.

두 방향 모두 첫 목업에서 비교할 수 있다. 새 연출의 세부 모양과 시간은 미정이다.

### 결정: 있는 타일과 이펙트로 평면도 그리기 (2026-11-11 사용자 "이 방향 채택")

프로젝트에 이미 있는 그림으로 1층 평면도 목업을 그렸고, 사용자가 이 방향을 채택했다. 방 위치, 방 크기(3칸), 복도 길이, 입구 굴은 지금 전투 비율 그대로다.

| 자리 | 그림 |
|---|---|
| 바닥·벽 | ElvGames Dark Castle(`FG_Dark_Dungeon`) 보라 돌바닥. 벽은 윗면 테두리를 두르고, 방·복도 북쪽에는 벽돌 면을 보인다(3/4 시점). 방마다 횃불 둘(`FG_Dark_Castle_Torch01`). 북쪽 벽은 방 이름판이 덮어 횃불은 양옆 벽 위쪽에 단다(2026-11-11 사용자 "횃불을 옆벽으로") |
| 함정 방 | 바닥에 묻힌 구멍 장치 넷(충전되면 붉게). 발동은 `MagicSpell6/StormSpell` 번개 |
| 문 제어실 | 홈 무늬 조작대와 바닥 용암 회로선 |
| 치유 샘 | 물웅덩이 애니메이션 타일(`FG_Dark_Castle_Purple_Pool`) |
| 금고 | 보물상자 셋과 항아리 |
| 심장 | 날개 달린 용암 기둥과 붉은 구슬 |
| 문 | 세로 복도(심장 문)는 용암 무늬 철문(`FG_Dark_Castle_Door01`), 가로 복도(샘·금고 문)는 기둥 막대 |

이어서 정한 것(2026-11-11 사용자 선택):

- **치유 샘:** 같은 웅덩이 그림에 푸른 물 색을 입힌다.
- **가로 복도 문(샘·금고):** 기둥 막대로 세운다.
- **함정 발동:** 번개(`StormSpell`)로 한다.
- **첫 구현 범위:** 바닥·벽·장치·문까지다. 꺼짐·고장·강조 같은 방 상태는 지금처럼 색을 덮어 보인다.

남은 미정: 효과음·음악. (방 상태 그림은 아래 "결정: 방 상태 그림"에서 정했다.)

- **안쪽 모서리(2026-11-12 사용자 목업 승인):** 타일셋에 벽 테두리 안쪽 모서리가 없어 바깥 모서리로 대신하던 자리(방 귀퉁이·복도 입구)에 작은 돌기가 남았다. 생성기가 가로·세로 테두리 조각에서 두 띠가 만나는 쪽만 남겨 안쪽 모서리 4장을 만든다(`Tilesets/Generated/RunRimInnerCorners.png`, 팩 원본은 그대로).

### 결정: 방 상태 그림 (2026-11-12 사용자 목업 승인)

| 상태 | 그림 |
|---|---|
| 꺼짐(시스템 방에 마력 없음) | 지금처럼 어두운 막 위에, 횃불 둘을 불 없는 화로(같은 팩)로 바꾸고 멈춘다. 장치(금고 상자·조작대·함정 구멍)와 샘은 회색(밝기 0.55)이 되고 샘 물결이 멈춘다 |
| 고장 | 붉은 테두리는 그대로 두고, 바닥에 불길 둘(횃불 불꽃만 잘라 2배, 깜빡임)과 검은 파편 넷·붉은 불씨 셋을 켠다. 자리는 방 종류와 상관없이 같다. 어두운 막 위에 그린다 |
| 심장 피해 | 심장 기둥 그림이 체력에 맞춰 어두워진다(체력 0에서 밝기 0.35). 체력 2/3 아래에서 핏자국 둘, 1/3 아래에서 셋을 더 켠다 |

원정 진지는 방 상태 그림을 쓰지 않는다. 값과 조각 자리는 `RunFloorArt.asset`(생성기 `RunFloorArtBuilder`)에 있다.

### 결정: 화면 글 줄이기 (2026-11-12 사용자 목업 승인 "이대로 구현")

"쓸데없는 글이 너무 많다"는 의견으로 네 곳을 줄였다.

| 자리 | 남긴 것 | 뺀 것 |
|---|---|---|
| 위기 카드 | "누가 · 어디 · 무엇" 한 줄 | 할 일 두 줄, 위기 때 저절로 열리던 아래 상성·도움말 띠(상성 버튼으로만 연다) |
| 준비 화면 | 적 카드 "이름 ● → 노리는 곳", "마력 N 남음", 부하 카드 이름·체력 | 위쪽 조작 안내 문장, 큰 기술 줄, 왼쪽 상성 줄·아래 팁 띠(씬에서 끔, `RunHudTrimBuilder`), 칸 수 안내, 부하 자리 글 |
| 전투 중 | 방 이름판은 이상할 때만 상태(고장·공격받는 중·끊김·꺼짐·문 부서짐), 함정 판 "준비 완료 / 피해 N" | 켜짐·쿨·심장 체력·금고 금화·입구 안내, 머리 위 목표 글(마우스를 올릴 때만), 부하 목록 자리 글, 함정 단계·"방 안 적 전원" |
| 전투 뒤 창 | 정비 창 상태 두 줄, 지도 칸 설명 1~2줄, 파견 창 이름·체력 | 상인 안내 줄·머리 글, 지도 범례 줄·"지면 런이 끝납니다", 파견 경고·승리 보상 줄 |

적 카드는 한 줄에 맞춰 높이 44로 줄였다(2026-11-12 사용자 요청, `RunHudTrimBuilder.ShrinkPartyCards`).

이어서(2026-11-12 사용자 선택): 마우스 설명 카드는 폭 280 두 줄(방 "이름 · 상태 / 내구 · 마력", 인물 "이름 · 체력 / 하는 일"), 누르면 뜨는 정보 창은 폭 300에 사용법 줄 없이 두세 줄이고, 두 창 모두 높이를 글에 맞춘다. 아래 상성표 띠와 "상성 ?" 버튼은 뺐다. 상성은 카드의 색 점으로만 보인다.

### 결정: 첫 판 안내 (2026-11-12 사용자 목업 승인 "이대로 구현")

"어떻게 플레이해야 하는지 모르겠다"는 의견으로, 할 일을 누를 곳 옆에 한 줄로 띄운다. 누를 곳은 금빛 테두리가 깜빡이고, 그 아래(화면 왼쪽 부하 카드는 오른쪽 옆)에 노란 줄이 붙는다. 안내는 클릭을 막지 않는다.

| 안내 | 뜨는 때 | 가리키는 곳 | 끝나는 때 |
|---|---|---|---|
| 구슬 눌러 함정 켜기 | 준비 화면, 함정 방 마력 0 | 함정 방 이름판 구슬 | 함정 방에 마력을 넣음 |
| 지금 누르기 | 함정이 준비됐고 함정 방에 적 | 함정 발동 버튼 | 함정 발동을 누름 |
| 부하 누르고 → ○○ 누르기 | 적이 금고·샘·심장에 닿았는데 지키는 부하 없음 | 가장 가까운 살아 있는 부하 카드, 고른 뒤에는 그 방("○○ 누르기") | 전투 중 이동 명령을 처음 내림 |
| 급하면 멈추고 명령 | 전투 시작 뒤 8초 | 멈춤 버튼 | 멈춤을 누름 |
| 끌어서 자리 옮기기 | 준비 화면, 상인에서 살린 부하가 있음(2026-11-12 추가) | 그 부하의 준비 카드(둘째 줄 "지난 판 쓰러짐") | 준비 화면에서 부하 자리를 옮김 |

- 2026-11-12 한 판 점검 뒤 추가(사용자 선택): "부하 보내기"는 지키는 부하가 없을 때뿐 아니라, 그 방을 지키는 부하가 모두 체력 1/3 아래일 때도 뜬다("버티는 부하가 위험하면 안내"). 상인에서 살린 부하는 예전 자리에 그대로 놓여 같은 곳에서 다시 쓰러지기 쉬워, 준비 카드에 "지난 판 쓰러짐"을 보이고 자리 안내를 띄운다("준비 화면에서 자리 안내"). 살린 부하 기록은 시연 저장(`RevivedMinions`)에 남고 다음 전투·원정이 끝나면 지운다.

- 한 번에 하나만, 겹치면 함정 발동 → 부하 보내기 → 멈춤 순이다. 원정에는 띄우지 않는다(원정은 할 일 안내가 따로 있다).
- **입구 첫 방 비우기 경고(2026-11-17 사용자 목업 승인 "A + B"):** 부하가 있는 방은 적이 지나가지 못해, 입구 첫 방(1층 북 함정 방)을 비우면 적이 함정 방에 묶이지 않는다. 시뮬레이션에서 이 방의 부하를 빼면 런이 무너졌다([시연 런 기획](DungeonFtlDemoRunDesign.md) "오크 주술사 체력").
  - B · 준비 화면: 그 방 이름판 둘째 줄에 "적을 막는 방"(흐린 글), 비어 있으면 주황 "빔 · 적 통과".
  - A · 전투 중: 그 방의 마지막 부하에게 다른 방으로 가라고 명령하면 한 줄 알림 "입구 첫 방이 비면 적이 지나갑니다"(2026-11-19 사용자 결정: 알림 칸 폭 272에 한 줄로 들어가게 줄임, 폭 235. 이전 문장은 320이라 두 줄로 넘쳤다). 알림은 실제 4초 동안 붙박고, 그동안 오는 다른 알림은 아래 줄에 붙는다(2026-11-19). 한 줄 알림에 나올 수 있는 문장 602개(이름 12·방 13·기술 7을 조합한 고장·체력 낮음·심장 진입·금고 도착·방 공격·문·폭파 예고·기술 예고)를 플레이 모드에서 재 보니 모두 칸 폭 272 안이었다. 가장 긴 것은 이 입구 경고(235)다(2026-11-19). 이름판은 지키는 부하가 없으면(나가는 중 포함) 주황 "빔 · 적 통과". 고장·공격받는 중이 먼저다.
  - 문구 줄임(2026-11-17 플레이 확인 뒤 사용자 "짧은 문구로"): 처음 넣은 "부하가 있으면 적이 멈춤"(147)·"비게 됨 · 적이 지나감"(128)·"비어 있음 · 적이 지나감"(142)이 이름판 칸(1920×1080에서 폭 99~102)에 넘쳐 말줄임되고 마력 구슬과 겹쳤다. 지금 문구는 75·70이다.
  - 첫 판 안내와 달리 경고라 기록하지 않고 매번 보인다. 원정에는 띄우지 않는다. 판단은 `RunEntryGuardRules`(머무는 부하 또는 그 방으로 가는 중인 부하가 있으면 지킴).
  - 궁수·견습 마법사·도적은 목표 방으로 가며 부하를 지나치므로(`RoomGoalsPassDefenders`) "적을 막는다"는 검사·공병·정예 방패병에 해당한다.
- "한 번 해 보면 끝"(사용자 선택): 기록은 런을 넘어 남는다(PlayerPrefs `run.coach.*`, 시연 저장과 별개). 설정 창의 "첫 판 안내 다시 보기"가 기록을 지운다(2026-11-12 사용자 목업 승인, 전투 중에 눌러도 바로 다시 뜬다). 설정 창은 타이틀과 DungeonRun에 같은 장부형 창(`SettingsScreen`)을 놓았다. 타이틀 "설정" 버튼과 ESC로 열고, 떠 있는 동안 전투는 흐르지 않는다. "다시 시작"은 두 씬에서 숨기고 "타이틀로"는 전투에서만 보인다. 타이틀의 옛 설정 창은 크기 0으로 놓여 보이지 않아 껐다.
- 멈춤 안내의 8초는 구현 때 정한 값이다.

### 결정: 부하 이동 목적지 (2026-11-12 사용자 승인)

| 화면 상태 | 평면도 표시 |
|---|---|
| 일시정지 중 해골 검사를 치유 샘으로 보냄 | 치유 샘 안 위쪽에 `해골 검사 · 이동 예약` |
| 해골 검사가 치유 샘으로 이동 중 | 같은 자리에 `해골 검사 · 이동 중` |
| 목적지에 도착하기 전에 교전 | 같은 자리에 `해골 검사 · 교전 중` |
| 목적지를 바꿈 | 표시를 새 목적지로 옮김 |
| 도착·선택 해제·사망·전투 종료 | 표시 숨김 |

이어서(2026-11-12 사용자 선택): 부하 정보 창이 목적지 줄을 가리면 머리 위 반대쪽 → 발 아래 양쪽 순으로 비켜 뜬다("정보 창이 비켜 뜨기"). 정보 창 첫 줄은 목적지 줄과 같은 말을 쓴다: 멈춘 채 새로 내린 명령은 "금고로 이동 예약", 이동 명령이 있으면 잠깐 서 있어도 "금고로 가는 중", 교전·후퇴는 원래 글("목적지 줄과 맞추기").

한 번에 선택한 부하 한 명의 목적지만 보여 준다. 진행 중인 명령을 일시정지하면 마지막 이동·교전 상태를 표시한다. 전투 준비 배치와 후퇴 중에는 목적지를 표시하지 않는다. 폭파 예고와 결과는 방 아래쪽을 사용한다.

### 결정: 함정 예약 취소 표시 (2026-11-12 사용자 승인)

함정 패널의 상태 줄에 `발동 예약됨`을 표시한다. 재개할 때 예약이 취소되면 `예약 취소 · 함정 꺼짐`처럼 판정 시점의 이유를 2초 동안 표시한 뒤 현재 상태로 돌아간다. 새 예약이 들어오면 예약 상태를 먼저 표시한다.

### 결정: 심장 공격 표시 (2026-11-12 사용자 승인)

심장을 공격하는 적이 있는 동안 심장 이름판에 붉은 `공격받는 중`을 표시한다. 해당 적에 마우스를 올리면 기존 설명 카드에 `심장 공격 중`이 나온다. 심장을 치는 적이 모두 교전으로 전환하거나 쓰러지면 이름판의 경고를 숨긴다.

### 결정: 부하 목록의 낮은 체력 표시 (2026-11-12 사용자 승인)

살아 있는 부하의 체력이 기존 알림 기준(시연판 30% 미만)에 해당하면 왼쪽 카드의 체력 막대와 `체력 낮음` 문구를 붉게 표시한다. 기준 이상으로 회복하면 문구를 숨기고 막대 색을 되돌린다. 쓰러진 부하는 `쓰러짐`을 표시한다.

### 결정: 정비 창의 이월 상태 (2026-11-12)

| 위치 | 표시 예시 |
|---|---|
| 제목 오른쪽 | 심장 18/30 |
| 본문 | 함정 방이 고장 났습니다. / 해골 검사(9/16)가 다쳤습니다. / 쓰러진 부하 · 해골 방패병 |
| 비용과 경고 | 금화 15 · 고치기 20 · 치료 20 / 금화가 모자랍니다 |

정비 창은 이어하기나 정비 구매 뒤에도 현재 이월 상태를 보여 준다. 쓰러진 부하 줄은 해당 부하가 있을 때만 뜬다. 수리·치료 화면에서 대상을 둘러보고, 금화가 충분할 때 결제한다. 원정 뒤 구매는 본진 이월 상태에 기록하고, 뒤의 원정 화면에는 파견 부하의 체력과 현재 금화만 맞춘다.

### 결정: 구역 지도에서 갈래 비교 (2026-11-12)

| 위치 | 표시 예시 |
|---|---|
| 지도 자원 줄 | 심장 18/30 · 금화 25 · 부하 3/4 · 부상 1명 · 유물 없음 |
| 들어갈 수 있는 상인 | 한 번 들를 때 2개까지 삽니다. / 심장 수리 30금화 (부족) · 부하 복귀 30금화 (부족) |
| 글 사건 | 굴 속 거래 · 부하 강화 또는 유물 / 제안에 따라 금화·심장·부하 체력·방 내구를 대가로 냅니다. |
| 들어갈 수 있는 진지 원정 | 기존 파견 인원·승리 조건·수비대 아래에 `승리 시 정예전 마력 +1 · 후퇴해도 런 계속` |

상인 설명에는 현재 필요한 수리·복귀의 개별 가격을 표시한다. 들어갈 수 있는 상인 칸에서 두 항목이 모두 필요하고 둘을 살 금화가 모자라면 가격 아래에 `둘 다 사려면 15금화 더 필요`처럼 부족분을 표시한다. 글 사건의 개별 제안은 진입할 때 확인한다.

### 결정: 원정 파견 최소 인원 안내 (2026-11-12 사용자 승인)

파견 인원이 0명인 상태로 마지막 생존 후보에 도달하면 `원정에는 최소 1명이 필요합니다`와 `다시 선택`·`파견` 버튼을 표시한다. 이미 한 명 이상 골랐다면 마지막 후보의 `남기기`는 진입 경로 선택으로 이어진다.

### 결정: 원정 후퇴 중 부하 상태 (2026-11-12 사용자 승인)

후퇴 명령 뒤 왼쪽 부하 카드에 `철수 중`, `귀환 완료`, `쓰러짐`을 구분해 표시한다. 입구에 도착해 전장을 나간 부하는 `귀환 완료`로 바뀐다. 체력이 낮은 부하의 막대는 붉게 표시한다.

## 목업 확인 기준

- 화면을 보자마자 입구에서 심장까지의 길, 부하가 있는 방, 현재 켜진 장치를 찾을 수 있다.
- 위기 카드가 떠도 위험한 방과 그 안의 부하, 이동 목적지를 동시에 볼 수 있다.
- 폭발과 고장은 화면에서 발생 위치가 분명하고, 색과 소리 외에도 방 모양이나 상태 문구로 구분된다.
