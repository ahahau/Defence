# 유닛 부활 마력 규칙

## 목적

유닛 사망이 영구 손실이 되지는 않되, 금화를 빚으로 바꿔 즉시 되살아나는 방식은 피한다.

## 구현 규칙

- `MagicManager`의 주둔 마력은 배치 슬롯 전용으로 유지한다.
- `UnitRevivalSystem`은 독립된 부활 마력 풀을 가진다. 기본 최대치는 30이고 초당 1씩 자연 회복한다.
- 부활 비용은 기본 15에 유닛 레벨당 8을 더한다.
- 쓰러진 유닛은 20초 뒤 부활 가능 상태가 되며, 마력이 부족하면 먼저 쓰러진 유닛부터 FIFO로 기다린다.
- 부활은 부활 마력만 소비하며 금화·부채를 발생시키지 않는다. 피로와 부상은 유지한다.

## 등급 보정

- 던전 등급 1점마다 부활 마력 최대치를 3, 초당 자연 회복량을 0.1 올린다.
- 유닛 레벨당 비용 +8 규칙은 유지한다.
- 현재 유닛 특성·성격은 기존 전투·피로 효과만 유지하며 부활 비용에는 보정하지 않는다.
- 유닛 역할 데이터가 별도 필드로 확정되면 역할별 부활 보정을 이 항목에 추가한다.

## 후속 작업

- 유닛 역할 데이터가 확정되면 역할별 부활 보정을 추가한다.
