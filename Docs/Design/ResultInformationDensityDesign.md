# 결과창 정보량 축소

2026-10-26 사용자 승인: 정산창과 판 종료창 모두 핵심 결과만 기본 표시하고 나머지는 상세 보기로 제공한다.

- 정산: 자금 증감, 간단한 제압/함정 결과, 목표 달성, 청산액을 기본 표시한다. 보스 예고·파산 위험은 숨기지 않는다. 전체 메모·금고/선지출 설명·개별 피로는 상세 보기로 연다. 부하/시설 전체 해금 목록은 매 정산마다 접힌 상태로 시작하고 기존 버튼으로 연다.
- 정산 메모에 표시용 SummaryText를 두어 문장 파싱 없이 핵심 여부를 구분한다. 기존 전문·금액·정산 계산·저장 형식은 유지한다.
- 판 종료: 생존 일수/최고 기록, 처치/보스, 진행 막대/이번 획득, 새 해금을 기본 표시한다. 상세 버튼은 기존 전과 8줄 전체를 열고 접는다. 새 결과가 열릴 때 기본 요약으로 돌아온다. 진행도 산식의 중복 문구는 빼고 획득 수치·막대·다음 단계는 유지한다. 새 해금이 없으면 짧게 표시한다.
- 글자 크기를 줄이지 않는다. 타이틀·새 판·정산 완료·ESC·수입/지출/대출/고용 탭과 경제 계산은 유지한다. 기존 프리팹을 부분 수정하고 생성기도 같은 필드와 배치를 재현한다.
- 검증: 실제 프리팹에서 기본 접힘/펼침/재열기 초기화/콜백 중복 없음/전문과 수치 보존을 확인한다. 1280×720 및 1920×1080에서 기본·상세·해금·빈 결과·패배 화면을 확인하고 원본 저장은 백업 후 복원한다.
